  Susun KRS mahasiswa dengan abstract class jalur studi, frozen data class yang dapat diurutkan, dan validasi NIM pada __post_init__().
prompt: |
  Tugas

  Lengkapi sistem pengisian KRS. Setiap mahasiswa terdaftar pada satu jalur studi yang menentukan batas SKS. Mata kuliah disimpan sebagai data yang tidak boleh berubah dan dapat diurutkan.

  1. Tujuan tugas

  Terapkan abstract class, concrete method di dalam abstract class, data class dengan `default_factory`, `__post_init__()`, `@dataclass(frozen=True, order=True)`, serta pengurutan tanpa mengubah list asli.

  2. Spesifikasi class `Jalur` (abstract class)

  - `label()` dan `batas_sks()` adalah abstract method.
  - `sisa_sks(terpakai)` mengembalikan `self.batas_sks()` dikurangi `terpakai`.
  - `Reguler`: `label()` mengembalikan `"Reguler"`, `batas_sks()` mengembalikan `24`.
  - `PertukaranPelajar`: `label()` mengembalikan `"Pertukaran Pelajar"`, `batas_sks()` mengembalikan `20`.

  3. Spesifikasi data class `MataKuliah`

  - Frozen dan dapat diurutkan: `@dataclass(frozen=True, order=True)`.
  - Field berurutan `sks: int`, `kode: str`, `nama: str`. Urutan field menentukan urutan pengurutan, yaitu berdasarkan `sks` lalu `kode`.

  4. Spesifikasi data class `Mahasiswa`

  - Field `nama: str`, `nim: str`, `jalur: Jalur`, dan `krs: list[MataKuliah]` dengan default list kosong baru.
  - `__post_init__()` melempar `ValueError("NIM harus 11 digit angka.")` jika `nim` tidak tepat 11 karakter atau tidak seluruhnya digit.
  - `total_sks()` mengembalikan jumlah SKS seluruh mata kuliah di `krs`.
  - `ambil(matkul)` menolak jika mata kuliah yang sama sudah ada di `krs` (gunakan perbandingan `==` hasil data class) atau jika total SKS akan melebihi `jalur.batas_sks()`. Jika diterima, tambahkan ke `krs` lalu kembalikan `True`.
  - `terurut()` mengembalikan list baru berisi `krs` yang sudah diurutkan. List `krs` sendiri tidak boleh ikut berubah urutannya.

  5. Program utama dan output

  Input baris pertama: `nama nim jalur`, dengan `jalur` bernilai `reguler` atau `pertukaran`. Baris kedua: jumlah mata kuliah `n`. Lalu `n` baris berformat `kode sks nama_mk`.

  Jika NIM tidak valid, output hanya dua baris: `Error` dan `Jalur Abstract`. Jika valid, output tepat sepuluh baris: `Nama`, `Jalur`, `Ambil`, `Total SKS`, `Sisa SKS`, `Terurut`, `KRS`, `MK Pertama`, `Mahasiswa Lain`, dan `Jalur Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `Terurut` berbeda dari `KRS` jika urutan pengambilan tidak sesuai urutan SKS dan kode.
  - `KRS` tetap mengikuti urutan pengambilan karena `terurut()` tidak mengubah list asli.
  - `Mahasiswa Lain` bernilai `0`.
  - Mata kuliah yang sama tidak dapat diambil dua kali.
