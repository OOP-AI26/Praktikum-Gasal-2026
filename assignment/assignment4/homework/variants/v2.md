  Susun hierarki pegawai dengan abstract property, abstract class bertingkat, dan slip gaji berupa frozen data class yang direvisi melalui replace().
prompt: |
  Tugas

  Bagian keuangan kampus membuat slip gaji untuk dosen dan tendik. `Dosen` hanya kerangka untuk jenjang jabatan dosen, sehingga object `Dosen` tidak boleh dibuat langsung. Slip yang sudah dibuat tidak boleh diubah; revisi menghasilkan slip baru.

  1. Tujuan tugas

  Terapkan abstract property, abstract method, abstract class bertingkat, `super()` pada abstract class, frozen data class, dan `replace()`.

  2. Spesifikasi data class `SlipGaji`

  - Frozen data class dengan field `nama: str`, `jabatan: str`, dan `total: int`.

  3. Spesifikasi class `Pegawai` (abstract class)

  - Class attribute `total_pegawai = 0`. Constructor menerima `(nama)`, menyimpannya, lalu menambah `Pegawai.total_pegawai` melalui nama class.
  - `gaji_pokok` adalah abstract property. `jabatan()` adalah abstract method.
  - `tunjangan()` mengembalikan `0`.
  - `buat_slip()` mengembalikan `SlipGaji(nama, jabatan(), gaji_pokok + tunjangan())`.

  4. Spesifikasi turunan

  - `Dosen(Pegawai)`: class attribute `tunjangan_per_sks = 100000`. Constructor menerima `(nama, sks)`, memanggil `super().__init__(nama)`, lalu menyimpan `sks`. `tunjangan()` dioverride menjadi `sks * tunjangan_per_sks`. Class ini tidak mengimplementasikan `gaji_pokok` maupun `jabatan()`, sehingga masih abstract.
  - `Lektor(Dosen)`: `gaji_pokok` bernilai `5000000`, `jabatan()` mengembalikan `"Lektor"`.
  - `GuruBesar(Dosen)`: `gaji_pokok` bernilai `8000000`, `jabatan()` mengembalikan `"Guru Besar"`. `tunjangan()` dioverride menjadi `super().tunjangan() + 2000000`.
  - `Tendik(Pegawai)`: constructor menerima `(nama, lembur)`, memanggil `super().__init__(nama)`, lalu menyimpan `lembur`. `gaji_pokok` bernilai `3500000`, `jabatan()` mengembalikan `"Tendik"`, `tunjangan()` mengembalikan `lembur * 75000`.

  5. Spesifikasi function `revisi_slip(slip, potongan)`

  - Jika `potongan` tidak lebih dari nol atau melebihi `slip.total`, kembalikan object `slip` yang sama.
  - Jika valid, kembalikan slip baru melalui `replace()` dengan `total` dikurangi `potongan`.

  6. Program utama dan output

  Input: `nama jenis angka potongan`. `jenis` bernilai `lektor`, `gurubesar`, `tendik`, atau `dosen`. `angka` berarti SKS untuk dosen dan jam lembur untuk tendik.

  Jika object gagal dibuat karena class masih abstract, output tepat tiga baris: `Gagal`, `Pegawai Abstract`, dan `Total Pegawai`. Jika berhasil, output tepat delapan baris: `Jabatan`, `Gaji Pokok`, `Tunjangan`, `Slip`, `Revisi`, `Object Sama`, `Pegawai Abstract`, dan `Total Pegawai`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `gaji_pokok` dipanggil sebagai property, tanpa tanda kurung.
  - `tunjangan()` pada `GuruBesar` memakai `super().tunjangan()`, bukan menuliskan angka totalnya.
  - `Total Pegawai` bernilai `0` jika object gagal dibuat, karena constructor tidak pernah dijalankan untuk abstract class.
  - `Object Sama` bernilai `True` hanya jika potongan ditolak.
