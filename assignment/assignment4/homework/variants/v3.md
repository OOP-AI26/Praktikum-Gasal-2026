  Kelola riwayat servis kendaraan kampus dengan abstract class, factory method berbasis cls, default argument None, dan deep copy untuk cadangan data.
prompt: |
  Tugas

  Unit transportasi kampus mencatat riwayat servis mobil dinas, motor kurir, dan bus kampus. Sebelum mencatat servis baru, sistem membuat cadangan data kendaraan. Cadangan tersebut tidak boleh ikut berubah ketika riwayat asli bertambah.

  1. Tujuan tugas

  Terapkan abstract class, factory `@classmethod` yang memakai `cls(...)`, jebakan default argument mutable, aliasing, dan `copy.deepcopy()`.

  2. Spesifikasi class `Kendaraan` (abstract class)

  - Constructor menerima `(plat, riwayat=None)`. Simpan `plat`. Jika `riwayat` bernilai `None`, buat list kosong baru. Jangan memakai `[]` sebagai default parameter.
  - `@classmethod dari_teks(cls, teks)` menerima format `plat;item1,item2`. Bagian setelah `;` bernilai `-` jika belum ada riwayat. Ubah underscore menjadi spasi pada plat dan setiap item, lalu buat object melalui `cls(...)`.
  - `jenis()` dan `interval_servis()` adalah abstract method.
  - `perlu_servis(km)` mengembalikan `True` jika `km` lebih dari atau sama dengan `interval_servis()`.
  - `catat_servis(item)` menolak jika `item` sudah ada di `riwayat`. Jika diterima, tambahkan ke `riwayat` lalu kembalikan `True`.
  - `buat_cadangan()` mengembalikan salinan menyeluruh object melalui `copy.deepcopy(self)`.

  3. Spesifikasi concrete class

  - `Mobil`: `jenis()` mengembalikan `"Mobil"`, `interval_servis()` mengembalikan `10000`.
  - `Motor`: `jenis()` mengembalikan `"Motor"`, `interval_servis()` mengembalikan `4000`.
  - `BusKampus(Mobil)`: `jenis()` dioverride menjadi `"Bus Kampus"`, `interval_servis()` dioverride menjadi `15000`.

  4. Program utama dan output

  Input: `jenis data km item_baru`. `jenis` bernilai `mobil`, `motor`, atau `bus`. `data` berformat `plat;riwayat`. Underscore pada `item_baru` diubah menjadi spasi oleh program utama.

  Program utama membuat kendaraan melalui `dari_teks`, membuat cadangan, mencatat servis baru, lalu membuat dua kendaraan baru tanpa riwayat dan mencatat servis pada kendaraan baru pertama saja.

  Output harus tepat sembilan baris: `Plat`, `Jenis`, `Class`, `Perlu Servis`, `Catat`, `Riwayat`, `Riwayat Cadangan`, `Kendaraan Baru`, dan `Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `Class` bernilai `BusKampus` jika `dari_teks` dipanggil dari `BusKampus`, karena factory memakai `cls(...)`.
  - `Riwayat Cadangan` tidak memuat servis baru.
  - `Kendaraan Baru` bernilai `[]` karena kendaraan baru kedua tidak berbagi list dengan kendaraan baru pertama.
