prompt: |
  Tugas

  Mahasiswa memakai dompet digital untuk membayar UKT, fotokopi, dan parkir motor. Ketiga tagihan tersebut berasal dari class yang tidak saling terkait, tetapi sama-sama memiliki method `tagihan()`. Buku pinjaman perpustakaan tidak memiliki tagihan sehingga tidak dapat dibayar.

  1. Tujuan tugas

  Terapkan `Protocol` dengan `@runtime_checkable`, structural typing, abstract class, data class dengan `default_factory`, dan frozen data class.

  2. Spesifikasi `BisaDibayar` dan class tagihan

  - `BisaDibayar` adalah `Protocol` yang dapat diperiksa dengan `isinstance()`, berisi satu method `tagihan(self) -> int`.
  - `TagihanUKT(nominal)`: `tagihan()` mengembalikan `nominal`.
  - `Fotokopi(lembar)`: `tagihan()` mengembalikan `300 * lembar`.
  - `ParkirMotor(jam)`: `tagihan()` mengembalikan `2000 * jam`.
  - `BukuPinjaman(judul)`: tidak memiliki method `tagihan()`.
  - Keempat class tersebut tidak mewarisi `BisaDibayar`.

  3. Spesifikasi class `Promo` (abstract class)

  - `potongan(nominal)` adalah abstract method.
  - `harga_akhir(nominal)` mengembalikan `nominal - self.potongan(nominal)`.
  - `TanpaPromo`: potongan selalu `0`.
  - `PromoMahasiswa`: potongan `nominal // 10`, tetapi paling besar `5000`.

  4. Spesifikasi data class

  - `Transaksi` adalah frozen data class dengan field `item: str` dan `bayar: int`.
  - `Dompet` adalah data class dengan field `pemilik: str`, `saldo: int`, `promo: Promo`, dan `riwayat: list[Transaksi]` dengan default list kosong baru.
  - `Dompet.bayar(item)` menolak jika `item` tidak sesuai `BisaDibayar`, jika `tagihan()` tidak lebih dari nol, atau jika harga setelah promo melebihi `saldo`. Jika diterima, kurangi `saldo`, simpan `Transaksi(nama class item, harga setelah promo)`, lalu kembalikan `True`.

  5. Program utama dan output

  Input baris pertama: `pemilik saldo promo`, dengan `promo` bernilai `mhs` atau `none`. Baris kedua: jumlah item `n`. Lalu `n` baris berformat `jenis nilai`, dengan `jenis` bernilai `ukt`, `fotokopi`, `parkir`, atau `buku`.

  Output harus tepat sembilan baris: `Pemilik`, `Bayar`, `Saldo`, `Riwayat`, `Total Keluar`, `Transaksi Terakhir`, `Dompet Lain`, `Buku Bisa Dibayar`, dan `Promo Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `Buku Bisa Dibayar` bernilai `False` tanpa memeriksa nama class secara manual.
  - Nama class item diperoleh dari `type(item).__name__`.
  - Pembayaran yang ditolak tidak mengubah `saldo` maupun `riwayat`.
  - `Dompet Lain` bernilai `0`.
