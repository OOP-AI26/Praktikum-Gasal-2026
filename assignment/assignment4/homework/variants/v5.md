  Atur antrean layanan akademik berdasarkan prioritas dengan abstract class layanan, frozen data class yang dapat diurutkan, dan pengurutan tanpa mengubah antrean asli.
prompt: |
  Tugas

  Loket layanan akademik melayani cuti akademik, legalisir ijazah, dan surat keterangan aktif kuliah. Layanan dengan nilai prioritas lebih kecil dipanggil lebih dahulu. Jika prioritasnya sama, nomor antrean yang lebih kecil dipanggil lebih dahulu.

  1. Tujuan tugas

  Terapkan abstract class, concrete method di dalam abstract class, `@dataclass(frozen=True, order=True)`, data class dengan `default_factory`, `sorted()` tanpa mengubah list asli, serta type hint `Tiket | None`.

  2. Spesifikasi data class `Tiket`

  - Frozen dan dapat diurutkan: `@dataclass(frozen=True, order=True)`.
  - Field berurutan `prioritas: int`, `nomor: int`, `kode: str`, dan `nama: str`.

  3. Spesifikasi class `Layanan` (abstract class)

  - `kode()` dan `prioritas()` adalah abstract method.
  - `buat_tiket(nomor, nama)` mengembalikan `Tiket(prioritas(), nomor, kode(), nama)`.
  - `CutiAkademik`: kode `"CUT"`, prioritas `1`.
  - `LegalisirIjazah`: kode `"LGL"`, prioritas `2`.
  - `SuratAktif`: kode `"SKA"`, prioritas `3`.

  4. Spesifikasi data class `Antrean`

  - Field `loket: str`, `tiket: list[Tiket]` dengan default list kosong baru, dan `nomor_terakhir: int = 0`.
  - `daftar(layanan, nama)` menambah `nomor_terakhir` satu, membuat tiket dengan nomor tersebut, menyimpannya ke `tiket`, lalu mengembalikan tiket tersebut. Nomor tidak boleh dihitung dari panjang list, karena tiket yang sudah dipanggil dihapus dari list.
  - `urutan()` mengembalikan list baru yang sudah diurutkan. List `tiket` tidak boleh ikut berubah urutannya.
  - `panggil()` mengembalikan `None` jika antrean kosong. Jika tidak, ambil tiket terkecil, hapus dari `tiket`, lalu kembalikan tiket tersebut.

  5. Program utama dan output

  Input baris pertama: nama loket (boleh mengandung spasi). Baris kedua: jumlah pendaftar `n`. Lalu `n` baris berformat `layanan nama`, dengan `layanan` bernilai `cuti`, `legalisir`, atau `surat`. Baris berikutnya: jumlah pemanggilan. Baris terakhir: satu pendaftar susulan berformat `layanan nama` yang mendaftar setelah pemanggilan selesai.

  Output harus tepat sembilan baris: `Loket`, `Urutan`, `Daftar Asli`, `Dipanggil`, `Susulan`, `Sisa`, `Nomor Terakhir`, `Antrean Lain`, dan `Layanan Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `Daftar Asli` tetap mengikuti urutan pendaftaran.
  - Pemanggilan pada antrean kosong menghasilkan `-` pada daftar `Dipanggil`.
  - Nomor pendaftar susulan melanjutkan `nomor_terakhir`, walaupun sebagian tiket sudah dipanggil dan dihapus.
  - `Antrean Lain` bernilai `0`.
