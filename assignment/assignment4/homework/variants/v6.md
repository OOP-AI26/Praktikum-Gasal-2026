brief: |
  Hitung nilai akhir dengan abstract class skema penilaian, validasi di __post_init__(), dan revisi nilai melalui replace() pada frozen data class.
prompt: |
  Tugas

  Dosen menghitung nilai akhir dari nilai tugas, UTS, dan UAS dengan skema yang berbeda untuk mata kuliah teori dan praktikum. Nilai akhir yang sudah dibuat tidak boleh diubah langsung. Revisi nilai menghasilkan object baru dan tetap melalui validasi yang sama.

  1. Tujuan tugas

  Terapkan abstract class, concrete method di dalam abstract class, frozen data class, `__post_init__()`, `replace()`, serta type hint `tuple[float, float, float]`.

  2. Spesifikasi data class `NilaiAkhir`

  - Frozen data class dengan field `nim: str`, `kode_mk: str`, dan `nilai: float`.
  - `__post_init__()` melempar `ValueError("Nilai harus di antara 0 dan 100.")` jika `nilai` kurang dari `0` atau lebih dari `100`.
  - `huruf()` mengembalikan `"A"` jika nilai minimal `85`, `"B"` jika minimal `70`, `"C"` jika minimal `55`, `"D"` jika minimal `40`, dan `"E"` untuk selain itu.

  3. Spesifikasi class `SkemaPenilaian` (abstract class)

  - `nama()` dan `bobot()` adalah abstract method. `bobot()` mengembalikan tuple tiga bilangan untuk tugas, UTS, dan UAS.
  - `hitung(tugas, uts, uas)` mengembalikan `round(tugas * bobot_tugas + uts * bobot_uts + uas * bobot_uas, 2)`.
  - `buat_nilai(nim, kode_mk, tugas, uts, uas)` mengembalikan `NilaiAkhir(nim, kode_mk, hitung(...))`.
  - `SkemaTeori`: nama `"Teori"`, bobot `(0.2, 0.3, 0.5)`.
  - `SkemaPraktikum`: nama `"Praktikum"`, bobot `(0.5, 0.2, 0.3)`.

  4. Spesifikasi function `revisi(nilai, nilai_baru)`

  - Kembalikan object baru melalui `replace(nilai, nilai=nilai_baru)`. Karena `replace()` membuat object baru, `__post_init__()` ikut dijalankan dan nilai revisi yang tidak valid akan melempar `ValueError`.

  5. Program utama dan output

  Input: `nim kode_mk skema tugas uts uas nilai_baru`, dengan `skema` bernilai `teori` atau `praktikum`.

  Jika nilai akhir tidak valid, output tepat dua baris: `Error` dan `Skema Abstract`. Jika valid, output tepat tujuh baris: `Skema`, `Nilai`, `Huruf`, `Revisi`, `Nilai Lama`, `Ubah Langsung`, dan `Skema Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `Nilai Lama` tetap sama walaupun revisi berhasil.
  - `Ubah Langsung` bernilai `False` karena `NilaiAkhir` adalah frozen data class.
  - Revisi yang tidak valid menghasilkan baris `Revisi: Error - ...`.
