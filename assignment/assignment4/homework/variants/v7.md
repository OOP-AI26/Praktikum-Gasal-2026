prompt: |
  Tugas

  Asisten praktikum mengelola inventaris lab komputer. Isi lab dapat berupa perangkat listrik (komputer, proyektor, AC) maupun kursi lab yang tidak memiliki method `nyalakan()`. Lab baru sering dibuat dengan menduplikasi lab yang sudah ada, tetapi perubahan pada lab baru tidak boleh memengaruhi lab asli.

  1. Tujuan tugas

  Terapkan abstract class, duck typing dengan `try`/`except AttributeError`, nominal typing dengan `isinstance()`, data class dengan `default_factory`, dan penyalinan list agar tidak terjadi aliasing.

  2. Spesifikasi class `Perangkat` (abstract class)

  - Constructor menerima `(kode)` dan menyimpannya.
  - `nyalakan()` dan `daya()` adalah abstract method.
  - `Komputer`: `nyalakan()` mengembalikan `"Komputer <kode> siap dipakai"`, `daya()` mengembalikan `250`.
  - `Proyektor`: `nyalakan()` mengembalikan `"Proyektor <kode> menampilkan layar"`, `daya()` mengembalikan `300`.
  - `AC`: `nyalakan()` mengembalikan `"AC <kode> disetel 24 derajat"`, `daya()` mengembalikan `900`.

  3. Spesifikasi class `KursiLab`

  - Bukan turunan `Perangkat`. Constructor menerima `(kode)` dan menyimpannya. Tidak memiliki `nyalakan()` maupun `daya()`.

  4. Spesifikasi function `siapkan(daftar)`

  - Untuk setiap benda, panggil `benda.nyalakan()` dan simpan hasilnya ke list.
  - Jika terjadi `AttributeError`, simpan `"<NamaClass> <kode> dilewati"`. Nama class diperoleh dari `type(benda).__name__`.
  - Kembalikan list hasil. Jangan memeriksa jenis benda dengan `isinstance()` di function ini.

  5. Spesifikasi data class `Lab`

  - Field `nama: str`, `isi: list` dengan default list kosong baru, dan `batas_daya: int = 2000`.
  - `total_daya()` mengembalikan jumlah `daya()` dari isi yang merupakan `Perangkat` (gunakan `isinstance()`).
  - `tambah(benda)` menolak jika benda adalah `Perangkat` dan `total_daya() + benda.daya()` melebihi `batas_daya`. Benda yang bukan `Perangkat` selalu diterima. Jika diterima, tambahkan ke `isi` lalu kembalikan `True`.
  - `duplikat(nama_baru)` mengembalikan `Lab` baru dengan nama baru, `batas_daya` yang sama, dan list `isi` yang merupakan salinan, bukan list yang sama.

  6. Program utama dan output

  Input baris pertama: `nama_lab batas_daya`. Baris kedua: jumlah benda `n`. Lalu `n` baris berformat `jenis kode`, dengan `jenis` bernilai `komputer`, `proyektor`, `ac`, atau `kursi`. Baris terakhir: `nama_lab_baru jenis kode` untuk benda yang ditambahkan ke lab hasil duplikasi.

  Output terdiri dari: `Lab`, `Tambah`, `Total Daya`, satu baris untuk setiap isi lab asli dari hasil `siapkan()`, lalu `Lab Baru`, `Tambah Lab Baru`, `Isi Lab Asli`, `Isi Lab Baru`, `Lab Kosong`, dan `Perangkat Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `KursiLab` tetap masuk ke lab tetapi dilewati saat `siapkan()`.
  - `Isi Lab Asli` tidak bertambah ketika lab baru ditambah benda.
  - `Lab Kosong` bernilai `0`.
