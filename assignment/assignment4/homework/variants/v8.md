brief: |
  Kelola keranjang belanja koperasi kampus dengan abstract property kategori, diskon per kategori, dan item keranjang berupa frozen data class yang diganti melalui replace().
prompt: |
  Tugas

  Koperasi kampus menjual makanan, alat tulis, dan seragam. Setiap kategori memiliki aturan diskon sendiri. Item di keranjang disimpan sebagai frozen data class, sehingga penambahan jumlah pada produk yang sudah ada dilakukan dengan mengganti item lama dengan item baru.

  1. Tujuan tugas

  Terapkan abstract property, abstract method, concrete method di dalam abstract class, frozen data class, `replace()`, dan data class dengan `default_factory`.

  2. Spesifikasi class `Produk` (abstract class)

  - Constructor menerima `(nama, harga)` dan menyimpan keduanya.
  - `kategori` adalah abstract property. `diskon_persen()` adalah abstract method.
  - `harga_akhir()` mengembalikan `harga - harga * diskon_persen() // 100`.
  - `Makanan`: kategori `"Makanan"`, diskon `0`.
  - `AlatTulis`: kategori `"Alat Tulis"`, diskon `10`.
  - `Seragam`: kategori `"Seragam"`, diskon `5` jika `harga` minimal `100000`, selain itu `0`.

  3. Spesifikasi data class

  - `ItemKeranjang` adalah frozen data class dengan field `nama: str`, `jumlah: int`, dan `subtotal: int`.
  - `Keranjang` adalah data class dengan field `pemilik: str` dan `isi: list[ItemKeranjang]` dengan default list kosong baru.
  - `Keranjang.tambah(produk, jumlah)` menolak jika `jumlah` tidak lebih dari nol. Jika nama produk sudah ada di `isi`, ganti item tersebut pada posisi yang sama dengan hasil `replace()` yang jumlah dan subtotalnya sudah ditambah. Jika belum ada, tambahkan `ItemKeranjang(nama, jumlah, harga_akhir() * jumlah)` ke akhir `isi`. Kembalikan `True` jika diterima.
  - `Keranjang.total()` mengembalikan jumlah `subtotal` seluruh item.

  4. Program utama dan output

  Input baris pertama: nama pemilik (boleh mengandung spasi). Baris kedua: jumlah produk `n`. Lalu `n` baris berformat `jenis nama harga jumlah`, dengan `jenis` bernilai `makanan`, `atk`, atau `seragam`.

  Program utama menyimpan item pertama yang masuk ke keranjang, lalu mencetaknya kembali di akhir untuk memastikan item lama tidak ikut berubah.

  Program utama juga mencoba mengubah item pertama secara langsung.

  Output harus tepat sembilan baris: `Pemilik`, `Tambah`, `Isi`, `Total`, `Kategori`, `Item Pertama Awal`, `Item Bisa Diubah`, `Keranjang Lain`, dan `Produk Abstract`.

  Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC`; method atau property wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Jangan memakai list sebagai default parameter maupun class attribute yang seharusnya milik setiap object.
  - Operasi yang ditolak harus mengembalikan nilai sesuai kontrak dan tidak boleh mengubah state.
  - Output dibandingkan secara tepat. Jangan menambahkan `print` lain.

  Checklist sebelum Run Tests

  - `kategori` dipanggil sebagai property, tanpa tanda kurung.
  - Produk yang sama tidak menambah baris baru di `Isi`.
  - `Item Pertama Awal` tetap menampilkan jumlah awal karena item lama tidak diubah.
  - `Item Bisa Diubah` bernilai `False` karena `ItemKeranjang` adalah frozen data class.
  - `Keranjang Lain` bernilai `0`.
