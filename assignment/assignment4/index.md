# Assignment 4

**Abstract Method, Data Class, Mutability, dan Typing Style:** [Live Practicum 4]({{ 'assignment/assignment4/studycase4/' | relative_url }}) (in-class) dan [Homework 4]({{ 'assignment/assignment4/homework/' | relative_url }}) (take-home).

Pada assignment ini kamu akan membuat abstract class sebagai kontrak bagi class turunannya, menyimpan data dengan data class, menjaga data penting agar tidak berubah tanpa disengaja, dan memilih cara memeriksa jenis object. Perhatikan juga jebakan object mutable, misalnya list yang tanpa sengaja dipakai bersama oleh beberapa object.
