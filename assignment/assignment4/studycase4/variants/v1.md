prompt: |
  Tugas

  Toko online Mas Obie menerima pembayaran melalui transfer bank dan e-wallet. Setiap metode memiliki biaya admin yang berbeda, tetapi cara menghitung total bayarnya sama. Setiap pembayaran yang berhasil menghasilkan struk yang tidak boleh diubah lagi.

  1. Tujuan tugas

  Terapkan abstract class, abstract method, concrete method di dalam abstract class, data class, frozen data class, dan `default_factory`.

  2. Spesifikasi class `MetodePembayaran` (abstract class)

  - Mewarisi `ABC`. Class attribute `batas_transaksi = 5000000`.
  - Constructor menerima `(pemilik)` dan menyimpannya.
  - `nama_metode()` dan `biaya_admin(nominal)` adalah abstract method.
  - `total_bayar(nominal)` mengembalikan `nominal` ditambah hasil `self.biaya_admin(nominal)`.
  - `info()` mengembalikan `"<nama_metode()> a.n. <pemilik>"`.

  3. Spesifikasi concrete class

  - `Transfer`: `nama_metode()` mengembalikan `"Transfer Bank"`, `biaya_admin(nominal)` selalu `6500`.
  - `EWallet`: `nama_metode()` mengembalikan `"E-Wallet"`, `biaya_admin(nominal)` mengembalikan `nominal // 100`. Class ini menimpa `batas_transaksi` menjadi `2000000`.

  4. Spesifikasi data class

  - `Struk` adalah frozen data class dengan field `metode: str`, `nominal: int`, dan `total: int`.
  - `Kasir` adalah data class dengan field `toko: str` dan `riwayat: list[Struk]` yang default-nya list kosong baru.
  - `Kasir.bayar(metode, nominal)` menolak jika `nominal` tidak lebih dari nol atau melebihi `metode.batas_transaksi`. Jika diterima, buat `Struk(metode.nama_metode(), nominal, metode.total_bayar(nominal))`, simpan ke `riwayat`, lalu kembalikan `True`.
  - `Kasir.total_pemasukan()` mengembalikan jumlah `total` dari seluruh struk.

  5. Program utama dan output

  Input: `pemilik jenis nominal`, dengan `jenis` bernilai `transfer` atau `ewallet`. Underscore pada `pemilik` diubah menjadi spasi oleh program utama.

  Program utama juga membuat `Kasir` kedua, mencoba membuat object `MetodePembayaran` secara langsung, dan mencoba mengubah struk.

  Output harus tepat tujuh baris: `Info`, `Bayar`, `Struk`, `Total Pemasukan`, `Struk Toko Lain`, `Abstract`, dan `Struk Bisa Diubah`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC` dan method wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Record yang tidak boleh berubah wajib memakai `@dataclass(frozen=True)`.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh menambah isi list.

  Checklist sebelum Run Tests

  - `Abstract` bernilai `True` karena `MetodePembayaran` tidak dapat dibuat object-nya.
  - `Struk Toko Lain` bernilai `0` karena riwayat kedua kasir tidak tercampur.
  - `Struk Bisa Diubah` bernilai `False` karena struk adalah frozen data class.
