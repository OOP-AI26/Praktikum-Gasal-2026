  Lengkapi sistem sewa aula dan laboratorium kampus dengan abstract class, frozen data class untuk bukti sewa, dan data class jadwal sewa.
prompt: |
  Tugas

  Bagian umum kampus menyewakan aula dan laboratorium untuk kegiatan himpunan, UKM, maupun kelas tambahan. Setiap jenis fasilitas memiliki tarif dan batas lama sewa yang berbeda, tetapi cara menghitung biayanya sama. Setiap sewa yang berhasil menghasilkan bukti sewa yang tidak boleh diubah lagi.

  1. Tujuan tugas

  Terapkan abstract class, abstract method, concrete method di dalam abstract class, data class, frozen data class, dan `default_factory`.

  2. Spesifikasi class `Fasilitas` (abstract class)

  - Mewarisi `ABC`. Class attribute `batas_jam = 8`.
  - Constructor menerima `(nama)` dan menyimpannya.
  - `jenis()` dan `tarif_per_jam()` adalah abstract method.
  - `hitung_biaya(jam)` mengembalikan `self.tarif_per_jam()` dikali `jam`.
  - `info()` mengembalikan `"<nama> (<jenis()>) - Rp<tarif_per_jam()>/jam"`.

  3. Spesifikasi concrete class

  - `Aula`: `jenis()` mengembalikan `"Aula"`, `tarif_per_jam()` mengembalikan `250000`.
  - `Laboratorium`: `jenis()` mengembalikan `"Laboratorium"`, `tarif_per_jam()` mengembalikan `100000`. Class ini menimpa `batas_jam` menjadi `4`.

  4. Spesifikasi data class

  - `BuktiSewa` adalah frozen data class dengan field `fasilitas: str`, `peminjam: str`, `jam: int`, dan `biaya: int`.
  - `JadwalSewa` adalah data class dengan field `gedung: str` dan `daftar: list[BuktiSewa]` yang default-nya list kosong baru.
  - `JadwalSewa.sewa(fasilitas, peminjam, jam)` menolak jika `jam` tidak lebih dari nol atau melebihi `fasilitas.batas_jam`. Jika diterima, buat `BuktiSewa(fasilitas.nama, peminjam, jam, fasilitas.hitung_biaya(jam))`, simpan ke `daftar`, lalu kembalikan `True`.
  - `JadwalSewa.total_biaya()` mengembalikan jumlah `biaya` dari seluruh bukti sewa.

  5. Program utama dan output

  Input: `nama_fasilitas jenis peminjam jam`, dengan `jenis` bernilai `aula` atau `lab`. Underscore pada `nama_fasilitas` dan `peminjam` diubah menjadi spasi oleh program utama.

  Program utama juga membuat `JadwalSewa` kedua, mencoba membuat object `Fasilitas` secara langsung, dan mencoba mengubah bukti sewa.

  Output harus tepat tujuh baris: `Info`, `Sewa`, `Bukti`, `Total Biaya`, `Jadwal Gedung Lain`, `Abstract`, dan `Bukti Bisa Diubah`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC` dan method wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Record yang tidak boleh berubah wajib memakai `@dataclass(frozen=True)`.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh menambah isi list.

  Checklist sebelum Run Tests

  - `Abstract` bernilai `True` karena `Fasilitas` tidak dapat dibuat object-nya.
  - `Jadwal Gedung Lain` bernilai `0` karena daftar sewa kedua gedung tidak tercampur.
  - `Bukti Bisa Diubah` bernilai `False` karena bukti sewa adalah frozen data class.
