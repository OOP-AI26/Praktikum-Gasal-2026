prompt: |
  Tugas

  Perpustakaan kampus mencatat setiap pengembalian buku dan majalah. Setiap jenis koleksi memiliki denda keterlambatan dan batas keterlambatan yang berbeda, tetapi cara menghitung dendanya sama. Setiap pengembalian yang berhasil menghasilkan catatan yang tidak boleh diubah lagi.

  1. Tujuan tugas

  Terapkan abstract class, abstract method, concrete method di dalam abstract class, data class, frozen data class, dan `default_factory`.

  2. Spesifikasi class `Koleksi` (abstract class)

  - Mewarisi `ABC`. Class attribute `batas_hari = 30`.
  - Constructor menerima `(judul)` dan menyimpannya.
  - `jenis()` dan `denda_per_hari()` adalah abstract method.
  - `hitung_denda(hari_telat)` mengembalikan `self.denda_per_hari()` dikali `hari_telat`.
  - `info()` mengembalikan `"<jenis()>: <judul> - denda Rp<denda_per_hari()>/hari"`.

  3. Spesifikasi concrete class

  - `Buku`: `jenis()` mengembalikan `"Buku"`, `denda_per_hari()` mengembalikan `1000`.
  - `Majalah`: `jenis()` mengembalikan `"Majalah"`, `denda_per_hari()` mengembalikan `500`. Class ini menimpa `batas_hari` menjadi `14`.

  4. Spesifikasi data class

  - `CatatanKembali` adalah frozen data class dengan field `judul: str`, `peminjam: str`, `hari_telat: int`, dan `denda: int`.
  - `KartuAnggota` adalah data class dengan field `nama: str` dan `riwayat: list[CatatanKembali]` yang default-nya list kosong baru.
  - `KartuAnggota.kembalikan(koleksi, hari_telat)` menolak jika `hari_telat` kurang dari nol atau melebihi `koleksi.batas_hari`. Jika diterima, buat `CatatanKembali(koleksi.judul, self.nama, hari_telat, koleksi.hitung_denda(hari_telat))`, simpan ke `riwayat`, lalu kembalikan `True`.
  - `KartuAnggota.total_denda()` mengembalikan jumlah `denda` dari seluruh catatan.

  5. Program utama dan output

  Input: `judul jenis nama hari_telat`, dengan `jenis` bernilai `buku` atau `majalah`. Underscore pada `judul` dan `nama` diubah menjadi spasi oleh program utama.

  Program utama juga membuat `KartuAnggota` kedua, mencoba membuat object `Koleksi` secara langsung, dan mencoba mengubah catatan.

  Output harus tepat tujuh baris: `Info`, `Kembali`, `Catatan`, `Total Denda`, `Kartu Anggota Lain`, `Abstract`, dan `Catatan Bisa Diubah`.

  6. Aturan

  - Lengkapi TODO saja dan jangan mengubah program utama, nama class, signature, label, atau urutan operasi.
  - Abstract class wajib mewarisi `ABC` dan method wajib ditandai `@abstractmethod`.
  - Data class wajib memakai `@dataclass`. Field list wajib memakai `field(default_factory=list)`, bukan `[]`.
  - Record yang tidak boleh berubah wajib memakai `@dataclass(frozen=True)`.
  - Operasi yang ditolak harus mengembalikan `False` dan tidak boleh menambah isi list.

  Checklist sebelum Run Tests

  - Keterlambatan `0` hari tetap diterima dengan denda `0`.
  - `Abstract` bernilai `True` karena `Koleksi` tidak dapat dibuat object-nya.
  - `Kartu Anggota Lain` bernilai `0` karena riwayat kedua anggota tidak tercampur.
  - `Catatan Bisa Diubah` bernilai `False` karena catatan adalah frozen data class.
