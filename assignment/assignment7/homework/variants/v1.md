prompt: |
  Tugas: Impor Data Nilai Bertahan Error

  Data nilai praktikum datang dari teks `nim;nama;tugas;ujian`. Sebagian baris dapat rusak. Importir harus melaporkan setiap kesalahan dengan nomor baris dan kolom, menjaga baris valid tetap terpakai pada mode longgar, serta berhenti dengan penyebab yang jelas pada mode ketat.

  1. Spesifikasi

  - ImporError adalah base exception. FormatSalah, NilaiTidakValid, dan DuplikatNIM adalah subclass BarisError yang sudah disediakan. Lengkapi BarisError(nomor, kolom, alasan): simpan ketiga argumen sebagai attribute dan bentuk pesan `baris {nomor} kolom {kolom}: {alasan}`.
  - parse_angka(nomor, kolom, teks): konversi dengan int(). ValueError diterjemahkan menjadi NilaiTidakValid dengan alasan `{teks!r} bukan bilangan bulat` menggunakan `from`. Nilai di luar 0..100 menghasilkan NilaiTidakValid dengan alasan `{nilai} di luar 0..100` tanpa cause.
  - parse_baris(nomor, baris): pisahkan dengan `;` lalu strip setiap kolom. Periksa berurutan: jumlah kolom harus 4 (kolom `*`, alasan `butuh 4 kolom, ditemukan {jumlah}`), nim tepat 11 digit (alasan `{nim!r} harus 11 digit`), nama tidak kosong (alasan `tidak boleh kosong`), lalu tugas dan ujian. Kembalikan Mahasiswa baru.
  - Importir.impor(daftar_baris): nomor baris mulai 1. Setelah baris berhasil di-parse, NIM yang sudah diterima dari baris sebelumnya menghasilkan DuplikatNIM dengan alasan `{nim} sudah ada di baris {nomor_pertama}`. Baris yang gagal tidak dianggap diterima.
  - Mode longgar: tangkap BarisError per baris, simpan object exception-nya, lalu lanjutkan. Mode ketat: BarisError pertama diterjemahkan menjadi ImporGagal(nomor) dengan `from`.
  - impor() mengembalikan HasilImpor dengan list baru pada setiap pemanggilan, tidak mengubah list input, dan tidak menyimpan state antarpemanggilan. Jangan menangkap Exception secara umum.

  2. Format input

  Baris pertama mode (`ketat` atau `longgar`). Baris kedua n (0..20). n baris berikutnya adalah data mentah dan dapat rusak, tetapi tidak pernah kosong. Nama dapat mengandung spasi.

  3. Format output

  Program utama mencetak Mode. Pada keberhasilan, cetak daftar Data (`- nim nama nilai_akhir`, dengan nilai akhir `(40*tugas + 60*ujian) // 100`), daftar Kesalahan beserta jenis dan cause-nya, Ringkasan, dan Ulang Sama. Pada mode ketat yang gagal, cetak Dihentikan dan Sebab. Baris terakhir selalu Input Utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `longgar`
  - `6`
  - `25051204001;Andi Pratama;80;90`
  - `25051204002;Budi;70;sembilan`
  - `2505120400;Citra;90;90`
  - `25051204001;Andi Lagi;60;60`
  - `25051204004;Dewi;85`
  - ` 25051204005 ; Eka Putri ; 100 ; 75`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `Mode: longgar`
  - `Data:`
  - `- 25051204001 Andi Pratama 86`
  - `- 25051204005 Eka Putri 85`
  - `Kesalahan:`
  - `- NilaiTidakValid - baris 2 kolom ujian: 'sembilan' bukan bilangan bulat | sebab: ValueError`
  - `- FormatSalah - baris 3 kolom nim: '2505120400' harus 11 digit | sebab: -`
  - `- DuplikatNIM - baris 4 kolom nim: 25051204001 sudah ada di baris 1 | sebab: -`
  - `- FormatSalah - baris 5 kolom *: butuh 4 kolom, ditemukan 3 | sebab: -`
  - `Ringkasan: 2 valid, 4 salah`
  - `Ulang Sama: True True`
  - `Input Utuh: True`
