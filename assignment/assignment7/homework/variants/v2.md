  Tugas: Transaksi Koperasi dengan Rollback

  Koperasi mahasiswa memproses setoran dan penarikan. Beberapa perintah dapat dikelompokkan di antara `MULAI` dan `SELESAI` sebagai satu transaksi: jika satu langkah gagal, seluruh perubahan pada transaksi tersebut dibatalkan. Perintah di luar blok diperlakukan sebagai transaksi satu langkah.

  1. Spesifikasi

  - KoperasiError adalah base exception. PerintahSalah, RekeningTidakAda, SaldoKurang, Koperasi, terapkan(), dan kelompokkan() sudah disediakan.
  - TransaksiGagal(mulai, langkah): simpan kedua argumen sebagai attribute; pesan `transaksi baris {mulai} gagal pada langkah {langkah}`.
  - parse_perintah(baris): format `JENIS kode nominal` dengan tepat tiga bagian. ValueError dari unpacking atau int() diterjemahkan menjadi PerintahSalah(baris) dengan `from`. Jenis selain SETOR/TARIK atau nominal <= 0 menghasilkan PerintahSalah(baris) tanpa cause.
  - Transaksi adalah context manager. __enter__() menyimpan cadangan saldo dan mengembalikan object transaksi. __exit__() memulihkan cadangan dan mengubah dibatalkan menjadi True jika terjadi exception apa pun, termasuk bug. __exit__() tidak boleh menyembunyikan exception.
  - jalankan_unit(koperasi, mulai, daftar): jalankan langkah di dalam satu `with Transaksi(...)`. KoperasiError pada langkah ke-k diterjemahkan menjadi TransaksiGagal(mulai, k) dengan `from`, sehingga __exit__() melakukan rollback.
  - proses(koperasi, daftar_baris): tangkap TransaksiGagal per unit dan buat log seperti pada TODO. Exception lain tidak ditangkap.

  2. Format input

  Baris pertama n (0..10), lalu n baris `kode saldo` dengan saldo integer tidak negatif dan kode unik. Berikutnya m (0..25), lalu m baris perintah. Baris `MULAI` dan `SELESAI` selalu berpasangan dan tidak bersarang. Baris lain dapat rusak, tetapi tidak pernah kosong. Blok kosong dihitung berhasil dengan 0 langkah.

  3. Format output

  Satu log untuk setiap unit dengan nomor baris awal unit: `mulai OK k langkah` atau `mulai BATAL langkah k: NamaSebab: pesan sebab`. Setelah itu cetak Saldo, lalu pemeriksaan Bug Diteruskan, Tanpa Error, Unit Gagal, dan dua baris Parse dari program utama.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `A 100`
  - `B 50`
  - `C 0`
  - `9`
  - `SETOR A 25`
  - `MULAI`
  - `TARIK A 100`
  - `SETOR C 100`
  - `SELESAI`
  - `MULAI`
  - `TARIK B 30`
  - `TARIK B 30`
  - `SELESAI`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `1 OK 1 langkah`
  - `2 OK 2 langkah`
  - `6 BATAL langkah 2: SaldoKurang: saldo B 20 kurang dari 30`
  - `Saldo: ['A=25', 'B=50', 'C=100']`
  - `Bug Diteruskan: listrik padam ['X=10'] True`
  - `Tanpa Error: ['X=6'] False`
  - `Unit Gagal: transaksi baris 9 gagal pada langkah 2 | RekeningTidakAda ['X=6']`
  - `Parse: perintah salah: 'SETOR X sepuluh' | sebab: ValueError`
  - `Parse: perintah salah: 'SETOR X 0' | sebab: -`
