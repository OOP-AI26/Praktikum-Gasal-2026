prompt: |
  Tugas: Sinkronisasi Presensi dengan Percobaan Ulang

  Aplikasi presensi mengirim data kelas ke server kampus. Gangguan jaringan bersifat sementara sehingga pengiriman boleh diulang. Penolakan server bersifat permanen sehingga tidak boleh diulang. Bug yang tidak dikenali juga tidak boleh diulang atau disembunyikan.

  1. Spesifikasi

  - SinkronError adalah base exception. GangguanSementara, DataDitolak, ServerPresensi, dan RingkasanSinkron sudah disediakan.
  - GagalSetelahPercobaan(kode, jumlah): simpan kedua argumen sebagai attribute; pesan `{kode} gagal setelah {jumlah} percobaan`.
  - kirim_dengan_ulang(server, kode, maks_percobaan, log): jika maks_percobaan < 1, bangkitkan ValueError(`maks_percobaan minimal 1`) sebelum memanggil server. Panggil server.kirim(kode, percobaan) dengan nomor percobaan mulai 1.
  - GangguanSementara dicatat sebagai `{kode} #{percobaan} gangguan`, lalu dicoba lagi selama masih ada jatah. Simpan exception terakhir pada variabel lain karena nama setelah `except ... as` dihapus ketika blok except selesai.
  - DataDitolak dicatat sebagai `{kode} #{percobaan} ditolak`, lalu diteruskan tanpa diubah menggunakan `raise`. Keberhasilan dicatat sebagai `{kode} #{percobaan} terkirim` dan nomor percobaan dikembalikan.
  - Jika seluruh percobaan mengalami gangguan, bangkitkan GagalSetelahPercobaan(kode, maks_percobaan) dari gangguan terakhir menggunakan `from`.
  - sinkronkan(server, daftar_kode, maks_percobaan): proses kode sesuai urutan, kelompokkan hasilnya ke terkirim, ditolak, atau gagal, lalu kembalikan RingkasanSinkron baru. Exception di luar kedua jenis itu, misalnya KeyError karena bug server, harus diteruskan.

  2. Format input

  Baris pertama maks percobaan (1..5). Baris kedua n (0..10). n baris berikutnya `kode pola`, dengan kode unik. Pola berisi huruf T (gangguan), D (ditolak), atau O (berhasil) untuk percobaan ke-1, ke-2, dan seterusnya. Tanda `-` berarti pola kosong. Jika pola habis, percobaan berikutnya berhasil.

  3. Format output

  Program utama mencetak seluruh log, lalu Terkirim, Ditolak, Gagal, Panggilan Server, serta pemeriksaan Sebab Gagal, Batas Salah, dan Bug Diteruskan.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `4`
  - `PBO-A TO`
  - `PBO-B TTTT`
  - `PBO-C TD`
  - `PBO-D -`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `PBO-A #1 gangguan`
  - `PBO-A #2 terkirim`
  - `PBO-B #1 gangguan`
  - `PBO-B #2 gangguan`
  - `PBO-B #3 gangguan`
  - `PBO-C #1 gangguan`
  - `PBO-C #2 ditolak`
  - `PBO-D #1 terkirim`
  - `Terkirim: ['PBO-A', 'PBO-D']`
  - `Ditolak: ['PBO-C']`
  - `Gagal: ['PBO-B']`
  - `Panggilan Server: 8 True`
  - `Sebab Gagal: Q gagal setelah 2 percobaan | GangguanSementara 2 2`
  - `Batas Salah: maks_percobaan minimal 1 0`
  - `Bug Diteruskan: 2 []`
