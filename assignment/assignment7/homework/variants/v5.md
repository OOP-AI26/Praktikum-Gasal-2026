prompt: |
  Tugas: Mesin Tumpukan dengan Error Domain

  Mesin tumpukan menghitung nilai praktikum dengan perintah sederhana. Operasi bawaan list dan aritmetika Python dapat menimbulkan IndexError, ZeroDivisionError, atau ValueError. Pemakai mesin tidak perlu mengetahui detail itu, tetapi penyebabnya harus tetap tersimpan untuk debugging.

  1. Spesifikasi

  - MesinError adalah base exception. PerintahTidakDikenal, OperandTidakValid, TumpukanPenuh, PembagianNol, Mesin.jalankan(), dan _pastikan_muat() sudah disediakan.
  - TumpukanKurang(perintah, butuh, ada): simpan ketiga argumen sebagai attribute; pesan `{perintah} butuh {butuh} nilai, tersedia {ada}`.
  - push(teks): int() yang gagal diterjemahkan menjadi OperandTidakValid(teks) dengan `from`. Periksa kapasitas dengan _pastikan_muat() setelah konversi berhasil.
  - pop(): gunakan EAFP. IndexError diterjemahkan menjadi TumpukanKurang('POP', 1, 0) dengan `from`.
  - dup(): baca puncak secara EAFP; IndexError menjadi TumpukanKurang('DUP', 1, 0) dengan `from`. Setelah itu periksa kapasitas dan tambahkan salinan puncak.
  - hitung(perintah): a adalah nilai kedua dari atas dan b adalah puncak. Baca keduanya tanpa pop. IndexError menjadi TumpukanKurang(perintah, 2, jumlah_isi) dengan `from`. Hitung `a op b` memakai OPERASI; DIV adalah pembagian bulat `//`. ZeroDivisionError menjadi PembagianNol() dengan `from`. Operasi yang gagal tidak boleh mengubah tumpukan.
  - proses(mesin, daftar_baris): log setiap baris sesuai TODO. Tangkap MesinError saja.

  2. Format input

  Baris pertama batas kapasitas (1..10). Baris kedua m (0..20), lalu m baris perintah: `PUSH bilangan`, `POP`, `DUP`, `ADD`, `SUB`, `MUL`, atau `DIV`. Perintah dapat salah tulis, jumlah bagiannya salah, atau operand-nya bukan bilangan bulat. Baris perintah tidak pernah kosong.

  3. Format output

  Satu log untuk setiap perintah: `nomor OK [isi tumpukan]` atau `nomor GAGAL NamaException: pesan | sebab: NamaCause`, dengan `-` jika tidak ada cause. Setelah itu cetak Akhir serta pemeriksaan Atribut, Bagi Nol, Isi Aman, dan Bug Diteruskan.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `4`
  - `8`
  - `PUSH 6`
  - `PUSH 3`
  - `SUB`
  - `DIV`
  - `PUSH 0`
  - `DIV`
  - `POP`
  - `PUSH x`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `1 OK [6]`
  - `2 OK [6, 3]`
  - `3 OK [3]`
  - `4 GAGAL TumpukanKurang: DIV butuh 2 nilai, tersedia 1 | sebab: IndexError`
  - `5 OK [3, 0]`
  - `6 GAGAL PembagianNol: pembagian dengan nol | sebab: ZeroDivisionError`
  - `7 OK [3]`
  - `8 GAGAL OperandTidakValid: operand tidak valid: 'x' | sebab: ValueError`
  - `Akhir: [3]`
  - `Atribut: ADD 2 1 [7]`
  - `Bagi Nol: ZeroDivisionError [7, 0]`
  - `Isi Aman: [7, 0]`
  - `Bug Diteruskan: True`
