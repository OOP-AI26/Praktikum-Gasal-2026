prompt: |
  Tugas: Sesi Cetak dengan Kunci Printer

  Printer laboratorium hanya boleh dipakai satu pengguna dalam satu waktu. Setiap tugas cetak membuka sesi yang mengunci printer. Kunci harus selalu dilepas, apa pun yang terjadi di dalam sesi. Kekurangan kertas adalah kondisi yang sudah diperkirakan: dokumen dimasukkan ke antrean ulang dan program berlanjut. Error lain tetap diteruskan.

  1. Spesifikasi

  - CetakError adalah base exception. PrinterSibuk, DokumenTidakValid, Printer, dan proses() sudah disediakan.
  - KertasHabis(dokumen, butuh, sisa): simpan ketiga argumen sebagai attribute; pesan `kertas kurang untuk {dokumen}: butuh {butuh}, sisa {sisa}`.
  - SesiCetak.__enter__(): jika printer sedang dipakai, bangkitkan PrinterSibuk(pemakai) tanpa mengubah state. Jika tidak, kunci printer untuk pengguna, catat `{pengguna} kunci`, dan kembalikan object sesi.
  - SesiCetak.cetak(token): token berbentuk `dokumen:halaman` dengan tepat satu tanda titik dua. ValueError dari unpacking atau int() diterjemahkan menjadi DokumenTidakValid(token) dengan `from`. Dokumen kosong atau halaman <= 0 juga ditolak, tanpa cause. Halaman yang melebihi sisa kertas menghasilkan KertasHabis. Jika berhasil, kurangi kertas, catat dokumen ke printer.tercetak, dan tulis log `{pengguna} cetak {dokumen} {halaman}`.
  - SesiCetak.__exit__(): selalu lepaskan kunci. Untuk KertasHabis, masukkan dokumen ke antrean ulang, catat `{pengguna} lepas; {dokumen} ke antrean ulang`, lalu tekan exception dengan mengembalikan True. Untuk kondisi lain, catat `{pengguna} lepas` dan kembalikan False.
  - jalankan_tugas(): cetak seluruh token dalam satu sesi `with`. Dokumen setelah dokumen yang gagal tidak dicetak pada sesi tersebut. Halaman yang sudah tercetak tidak dikembalikan.
  - Perhatikan bahwa __exit__() tidak dipanggil jika __enter__() sendiri gagal.

  2. Format input

  Baris pertama jumlah kertas awal (0..100). Baris kedua m (0..15), lalu m baris perintah: `ISI jumlah` dengan jumlah integer positif yang valid, atau `CETAK pengguna token token ...` dengan nol token atau lebih. Token dapat rusak.

  3. Format output

  Program utama mencetak log, lalu Kertas, Tercetak, Antrean Ulang, Terkunci, serta pemeriksaan Bersarang, Bug Diteruskan, dan Sebab Dokumen.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `10`
  - `5`
  - `CETAK andi modul:4 laporan:3`
  - `CETAK budi poster:5 catatan:1`
  - `ISI 20`
  - `CETAK citra tugas:0`
  - `CETAK dewi kuis:2`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `andi kunci`
  - `andi cetak modul 4`
  - `andi cetak laporan 3`
  - `andi lepas`
  - `budi kunci`
  - `budi lepas; poster ke antrean ulang`
  - `baris 3 isi kertas -> 23`
  - `citra kunci`
  - `citra lepas`
  - `baris 4 GAGAL DokumenTidakValid: dokumen tidak valid: 'tugas:0'`
  - `dewi kunci`
  - `dewi cetak kuis 2`
  - `dewi lepas`
  - `Kertas: 21`
  - `Tercetak: ['modul', 'laporan', 'kuis']`
  - `Antrean Ulang: ['poster']`
  - `Terkunci: False`
  - `Bersarang: printer sedang dipakai A | None ['A kunci', 'A lepas']`
  - `Bug Diteruskan: None ['X kunci', 'X cetak a 1', 'X lepas']`
  - `Sebab Dokumen: ValueError`
