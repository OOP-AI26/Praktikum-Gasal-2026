  Tugas: Layanan Peminjaman Buku dan Kode Keluar

  Layanan perpustakaan memiliki lapisan data, aturan peminjaman, dan CLI. Lapisan data dan aturan hanya membangkitkan exception. CLI menjadi satu-satunya bagian yang menangkap error domain, menulis pesan, dan menentukan kode keluar seperti program terminal sungguhan.

  1. Spesifikasi

  - PerpusError adalah base exception. PermintaanTidakValid, AturanDilanggar beserta subclass-nya, Anggota, Buku, status(), layani(), ringkasan, dan urai() sudah disediakan.
  - DataTidakDitemukan(jenis, kunci): simpan kedua argumen sebagai attribute; pesan `{jenis} {kunci} tidak ditemukan`.
  - cari_anggota(kode) dan cari_buku(isbn): gunakan EAFP. KeyError diterjemahkan menjadi DataTidakDitemukan dengan jenis `anggota` atau `buku` menggunakan `from None`, karena KeyError internal tidak berguna bagi pemakai CLI.
  - pinjam(kode, isbn): cari anggota lalu buku. Periksa berurutan: AnggotaDiblokir, BatasPinjam jika jumlah pinjaman sudah mencapai batas, SudahMeminjam, lalu StokHabis. Setelah semua lolos, kurangi stok dan tambahkan isbn ke pinjaman. Pesan hasil `{kode} meminjam {isbn}, sisa {stok}`.
  - kembali(kode, isbn): cari anggota lalu buku. Anggota yang diblokir tetap boleh mengembalikan buku. Buku yang tidak sedang dipinjam anggota tersebut menghasilkan BelumDipinjam. Pesan hasil `{kode} mengembalikan {isbn}, sisa {stok}`.
  - jalankan_cli(perpus, baris, keluaran): urai dan layani permintaan. Tambahkan tepat satu pesan ke keluaran lalu kembalikan kode: 0 untuk berhasil (`OK pesan`), 2 untuk PermintaanTidakValid, 3 untuk DataTidakDitemukan, dan 1 untuk PerpusError lain (`ERROR pesan`). Urutan blok except menentukan hasil. Bug seperti AttributeError harus diteruskan.

  2. Format input

  Baris pertama a (0..5), lalu a baris `kode batas status` dengan status `aktif` atau `blokir`. Berikutnya b (0..5), lalu b baris `isbn stok`. Berikutnya r (0..15), lalu r baris permintaan: `pinjam kode isbn`, `kembali kode isbn`, atau `status isbn`. Permintaan dapat salah tulis atau jumlah bagiannya salah, tetapi tidak pernah kosong.

  3. Format output

  Untuk setiap permintaan cetak `[kode] pesan`. Setelah itu cetak daftar Kode, Stok, Pinjaman, serta pemeriksaan Konteks Disembunyikan dan Bug Diteruskan.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `A01 2 aktif`
  - `A02 1 blokir`
  - `2`
  - `B-PBO 1`
  - `B-AI 3`
  - `7`
  - `pinjam A01 B-PBO`
  - `pinjam A01 B-PBO`
  - `pinjam A02 B-AI`
  - `pinjam A09 B-AI`
  - `status B-PBO`
  - `pinjem A01 B-AI`
  - `kembali A01 B-PBO`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `[0] OK A01 meminjam B-PBO, sisa 0`
  - `[1] ERROR A01 sudah meminjam B-PBO`
  - `[1] ERROR A02 diblokir`
  - `[3] ERROR anggota A09 tidak ditemukan`
  - `[0] OK B-PBO stok 0`
  - `[2] ERROR permintaan tidak valid: 'pinjem A01 B-AI'`
  - `[0] OK A01 mengembalikan B-PBO, sisa 1`
  - `Kode: [0, 1, 1, 3, 0, 2, 0]`
  - `Stok: ['B-PBO=1', 'B-AI=3']`
  - `Pinjaman: ['A01:-', 'A02:-']`
  - `Konteks Disembunyikan: True True buku TIDAKADA`
  - `Bug Diteruskan: True`
