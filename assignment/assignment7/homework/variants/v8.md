prompt: |
  Tugas: Sensor Cadangan dan Rantai Exception

  Setiap ruang laboratorium memiliki sensor suhu utama dan cadangan. Jika sensor utama gagal, monitor mencoba sensor cadangan. Ketika keduanya gagal, laporan harus memperlihatkan seluruh rantai penyebab, sama seperti traceback Python.

  1. Spesifikasi

  - SensorError adalah base exception. SensorRusak, NilaiTidakMasukAkal, PembacaanGagal, RuangTidakDikenal, Sensor, dan pecah() sudah disediakan.
  - DataKorup(nama, teks): simpan kedua argumen sebagai attribute; pesan `{nama} mengirim data korup {teks!r}`.
  - baca_valid(sensor): ambil teks dari sensor.baca() dan biarkan SensorRusak diteruskan. ValueError dari float() diterjemahkan menjadi DataKorup dengan `from`. Nilai di luar -20..60, termasuk nan dan inf, menghasilkan NilaiTidakMasukAkal.
  - Monitor.baca_ruang(ruang): KeyError saat mencari ruang diterjemahkan menjadi RuangTidakDikenal dengan `from None`. Kembalikan `(nilai, 'utama')` jika sensor utama berhasil. Jika sensor utama gagal dengan SensorError, coba sensor cadangan di dalam blok except tersebut dan kembalikan `(nilai, 'cadangan')`. Jika cadangan juga gagal, bangkitkan PembacaanGagal(ruang) dari error cadangan menggunakan `from`. Karena dibangkitkan saat error utama sedang ditangani, error utama otomatis menjadi __context__.
  - Exception selain SensorError, misalnya RuntimeError dari firmware, tidak boleh memicu cadangan dan harus diteruskan.
  - rantai(error): kembalikan list nama class mulai dari error. Ikuti __cause__ jika ada; jika tidak ada dan __suppress_context__ bernilai True, berhenti; selain itu ikuti __context__ sampai None.

  2. Format input

  Baris pertama n (0..5), lalu n baris `ruang data_utama data_cadangan`. Data adalah token dipisah koma sesuai urutan pembacaan, atau `-` jika kosong. Token `E` berarti sensor tidak merespons; data yang habis juga dianggap tidak merespons. Baris terakhir berisi satu atau lebih nama ruang yang dibaca berurutan; ruang dapat dibaca lebih dari sekali atau tidak terdaftar.

  3. Format output

  Untuk setiap pembacaan cetak `ruang nilai dari sumber` dengan satu angka desimal, atau `ruang GAGAL pesan | rantai: A > B > ...`. Setelah itu cetak Berhasil serta pemeriksaan Tanpa Konteks, Rantai Uji, dan Bug Diteruskan.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `LAB1 24.5 -`
  - `LAB2 E 23`
  - `LAB3 abc E`
  - `LAB1 LAB2 LAB3 LAB9 LAB1`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `LAB1 24.5 dari utama`
  - `LAB2 23.0 dari cadangan`
  - `LAB3 GAGAL pembacaan LAB3 gagal | rantai: PembacaanGagal > SensorRusak > DataKorup > ValueError`
  - `LAB9 GAGAL ruang LAB9 tidak dikenal | rantai: RuangTidakDikenal`
  - `LAB1 GAGAL pembacaan LAB1 gagal | rantai: PembacaanGagal > SensorRusak > SensorRusak`
  - `Berhasil: 2 Cadangan: 1`
  - `Tanpa Konteks: ['RuangTidakDikenal'] True`
  - `Rantai Uji: ['PembacaanGagal', 'NilaiTidakMasukAkal', 'DataKorup', 'ValueError'] abc`
  - `Bug Diteruskan: firmware Z-utama crash 1`
