# Assignment 7

**Chapter 9 - Exceptions and robust error handling:** [Live Practicum 7]({{ '/assignment/assignment7/studycase7/' | relative_url }}) (in-class) dan [Homework 7]({{ '/assignment/assignment7/homework/' | relative_url }}) (take-home).

Tangani data dan perintah yang dapat rusak tanpa merusak state program. Tugas menekankan custom exception, penerjemahan error dengan `raise ... from ...`, penerusan exception dengan `raise`, rollback, context manager, serta penempatan `try`/`except`/`else`/`finally` yang hanya menangkap error domain dan membiarkan bug tetap terlihat.

- Live practicum menyediakan satu study case untuk setiap kelas: 2025A, 2025B, dan 2025C.
- Homework menyediakan delapan varian yang dipilih secara konsisten berdasarkan NIM.
- Setiap varian dilengkapi spesifikasi, starter code dengan TODO, dan delapan test case resmi.

Pelajari [Chapter 9]({{ '/readings-chapter9/' | relative_url }}) dan [Quick Review 9]({{ '/quickreview/quickreview9/' | relative_url }}) sebelum mengerjakan. Assignment ini menggunakan satu file Python.
