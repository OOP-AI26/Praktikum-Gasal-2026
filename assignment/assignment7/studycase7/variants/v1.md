  Tugas: Dompet Kantin Kampus

  Kantin kampus mencatat dompet digital mahasiswa. Setiap dompet memiliki saldo dan batas saldo. Perintah datang dari teks yang dapat rusak, sehingga setiap kegagalan harus dilaporkan per baris tanpa merusak saldo.

  1. Spesifikasi

  - KantinError, PerintahTidakValid, AkunTidakDitemukan, dan BatasSaldoTerlampaui sudah disediakan. Lengkapi constructor NominalTidakValid(nominal) dan SaldoTidakCukup(kode, saldo, diminta): simpan argumen sebagai attribute dengan nama yang sama, lalu panggil super().__init__() dengan pesan sesuai TODO.
  - Dompet.isi(nominal): tolak nominal <= 0 dengan NominalTidakValid(nominal); tolak jika saldo setelah ditambah melebihi batas dengan BatasSaldoTerlampaui; selain itu tambahkan.
  - Dompet.bayar(nominal): tolak nominal <= 0 dengan NominalTidakValid(nominal); tolak jika nominal lebih besar dari saldo dengan SaldoTidakCukup; selain itu kurangi.
  - Operasi yang ditolak tidak boleh mengubah saldo. Validasi dilakukan sebelum perubahan.
  - Kantin.cari(kode): gunakan EAFP. Akses dictionary di dalam try, lalu terjemahkan KeyError menjadi AkunTidakDitemukan(kode) dengan `from`.
  - Kantin.transfer(asal, tujuan, nominal): cari asal lalu tujuan sebelum mengubah apa pun. Panggil bayar() pada asal, lalu isi() pada tujuan. Jika langkah kedua gagal dengan KantinError, kembalikan nominal ke asal lalu teruskan exception yang sama dengan `raise`.
  - parse_nominal(teks): ubah teks menjadi int. ValueError diterjemahkan menjadi NominalTidakValid(teks) dengan `from`. Nilai nol atau negatif tidak diperiksa di sini, tetapi oleh isi()/bayar().
  - Prosesor.jalankan(daftar_baris): gunakan try/except/else/finally untuk setiap baris sesuai TODO. Tangkap KantinError saja. Exception lain, misalnya AttributeError karena bug, harus diteruskan; finally tetap menghitung baris tersebut.

  2. Format input

  Baris pertama n (0..10). n baris berikutnya: kode saldo batas, dengan 0 <= saldo <= batas dan kode unik tanpa spasi. Baris berikutnya m (0..20), lalu m baris perintah: `ISI kode jumlah`, `BAYAR kode jumlah`, atau `TRANSFER asal tujuan jumlah`. Perintah dapat rusak: kata perintah tidak dikenal atau bukan huruf kapital, jumlah bagian salah, jumlah bukan bilangan bulat, atau kode tidak terdaftar. Baris perintah tidak pernah kosong.

  3. Format output

  Program utama mencetak satu log untuk setiap perintah, lalu baris berlabel Saldo, Diproses, Sebab NominalTidakValid, Sebab AkunTidakDitemukan, Atribut SaldoTidakCukup, Atribut BatasSaldoTerlampaui, dan Bug Diteruskan. Log berhasil berbentuk `nomor OK hasil`; log gagal berbentuk `nomor GAGAL NamaException: pesan`. Representasi object adalah `kode=saldo`.

  Method proses_baris() dan program utama sudah disediakan; jangan diubah. proses_baris() mengonversi jumlah terlebih dahulu sebelum mencari kode, sehingga `ISI KODE_SALAH abc` gagal sebagai NominalTidakValid.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `A 100000 500000`
  - `B 450000 500000`
  - `C 0 300000`
  - `8`
  - `ISI A 50000`
  - `BAYAR C 1000`
  - `TRANSFER A B 60000`
  - `ISI B abc`
  - `TRANSFER A C 20000`
  - `BAYAR D 5000`
  - `TARIK A 1000`
  - `ISI A 0`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `1 OK A=150000`
  - `2 GAGAL SaldoTidakCukup: saldo C 0 kurang dari 1000`
  - `3 GAGAL BatasSaldoTerlampaui: saldo B melebihi batas 500000`
  - `4 GAGAL NominalTidakValid: nominal tidak valid: abc`
  - `5 OK A=130000 C=20000`
  - `6 GAGAL AkunTidakDitemukan: akun D tidak ditemukan`
  - `7 GAGAL PerintahTidakValid: perintah tidak valid: 'TARIK A 1000'`
  - `8 GAGAL NominalTidakValid: nominal tidak valid: 0`
  - `Saldo: ['A=130000', 'B=450000', 'C=20000']`
  - `Diproses: 8 Gagal: 6`
  - `Sebab NominalTidakValid: ValueError 12a`
  - `Sebab AkunTidakDitemukan: KeyError TIDAKADA`
  - `Atribut SaldoTidakCukup: UJI 100 150 100`
  - `Atribut BatasSaldoTerlampaui: UJI 100 100`
  - `Bug Diteruskan: 2 1 1`
