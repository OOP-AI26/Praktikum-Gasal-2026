  Tugas: Stok Rak Laboratorium

  Laboratorium menyimpan alat habis pakai di beberapa rak. Setiap rak memiliki stok dan kapasitas. Perintah datang dari teks yang dapat rusak, sehingga setiap kegagalan harus dilaporkan per baris tanpa merusak stok.

  1. Spesifikasi

  - LabError, PerintahTidakValid, RakTidakDitemukan, dan KapasitasPenuh sudah disediakan. Lengkapi constructor JumlahTidakValid(jumlah) dan StokTidakCukup(kode, stok, diminta): simpan argumen sebagai attribute dengan nama yang sama, lalu panggil super().__init__() dengan pesan sesuai TODO.
  - Rak.masuk(jumlah): tolak jumlah <= 0 dengan JumlahTidakValid(jumlah); tolak jika stok setelah ditambah melebihi kapasitas dengan KapasitasPenuh; selain itu tambahkan.
  - Rak.ambil(jumlah): tolak jumlah <= 0 dengan JumlahTidakValid(jumlah); tolak jika jumlah lebih besar dari stok dengan StokTidakCukup; selain itu kurangi.
  - Operasi yang ditolak tidak boleh mengubah stok. Validasi dilakukan sebelum perubahan.
  - Laboratorium.cari(kode): gunakan EAFP. Akses dictionary di dalam try, lalu terjemahkan KeyError menjadi RakTidakDitemukan(kode) dengan `from`.
  - Laboratorium.pindah(asal, tujuan, jumlah): cari asal lalu tujuan sebelum mengubah apa pun. Panggil ambil() pada asal, lalu masuk() pada tujuan. Jika langkah kedua gagal dengan LabError, kembalikan jumlah ke asal lalu teruskan exception yang sama dengan `raise`.
  - parse_jumlah(teks): ubah teks menjadi int. ValueError diterjemahkan menjadi JumlahTidakValid(teks) dengan `from`. Nilai nol atau negatif tidak diperiksa di sini, tetapi oleh masuk()/ambil().
  - Prosesor.jalankan(daftar_baris): gunakan try/except/else/finally untuk setiap baris sesuai TODO. Tangkap LabError saja. Exception lain, misalnya AttributeError karena bug, harus diteruskan; finally tetap menghitung baris tersebut.

  2. Format input

  Baris pertama n (0..10). n baris berikutnya: kode stok kapasitas, dengan 0 <= stok <= kapasitas dan kode unik tanpa spasi. Baris berikutnya m (0..20), lalu m baris perintah: `MASUK kode jumlah`, `AMBIL kode jumlah`, atau `PINDAH asal tujuan jumlah`. Perintah dapat rusak: kata perintah tidak dikenal atau bukan huruf kapital, jumlah bagian salah, jumlah bukan bilangan bulat, atau kode tidak terdaftar. Baris perintah tidak pernah kosong.

  3. Format output

  Program utama mencetak satu log untuk setiap perintah, lalu baris berlabel Stok, Diproses, Sebab JumlahTidakValid, Sebab RakTidakDitemukan, Atribut StokTidakCukup, Atribut KapasitasPenuh, dan Bug Diteruskan. Log berhasil berbentuk `nomor OK hasil`; log gagal berbentuk `nomor GAGAL NamaException: pesan`. Representasi object adalah `kode=stok/kapasitas`.

  Method proses_baris() dan program utama sudah disediakan; jangan diubah. proses_baris() mengonversi jumlah terlebih dahulu sebelum mencari kode, sehingga `MASUK KODE_SALAH abc` gagal sebagai JumlahTidakValid.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `R1 100 500`
  - `R2 450 500`
  - `R3 0 300`
  - `8`
  - `MASUK R1 50`
  - `AMBIL R3 1`
  - `PINDAH R1 R2 60`
  - `MASUK R2 abc`
  - `PINDAH R1 R3 20`
  - `AMBIL R4 5`
  - `BUANG R1 1`
  - `MASUK R1 0`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `1 OK R1=150/500`
  - `2 GAGAL StokTidakCukup: stok R3 0 kurang dari 1`
  - `3 GAGAL KapasitasPenuh: rak R2 melebihi kapasitas 500`
  - `4 GAGAL JumlahTidakValid: jumlah tidak valid: abc`
  - `5 OK R1=130/500 R3=20/300`
  - `6 GAGAL RakTidakDitemukan: rak R4 tidak ditemukan`
  - `7 GAGAL PerintahTidakValid: perintah tidak valid: 'BUANG R1 1'`
  - `8 GAGAL JumlahTidakValid: jumlah tidak valid: 0`
  - `Stok: ['R1=130/500', 'R2=450/500', 'R3=20/300']`
  - `Diproses: 8 Gagal: 6`
  - `Sebab JumlahTidakValid: ValueError 12a`
  - `Sebab RakTidakDitemukan: KeyError TIDAKADA`
  - `Atribut StokTidakCukup: UJI 100 150 100`
  - `Atribut KapasitasPenuh: UJI 100 100`
  - `Bug Diteruskan: 2 1 1`
