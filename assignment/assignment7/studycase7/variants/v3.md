  Tugas: Kuota Tiket Seminar

  Panitia seminar menjual tiket untuk beberapa sesi. Setiap sesi memiliki jumlah tiket terjual dan kuota. Perintah datang dari teks yang dapat rusak, sehingga setiap kegagalan harus dilaporkan per baris tanpa merusak data penjualan.

  1. Spesifikasi

  - SeminarError, PerintahTidakValid, SesiTidakDitemukan, dan TiketHabis sudah disediakan. Lengkapi constructor JumlahTidakValid(jumlah) dan PembatalanMelebihi(kode, terjual, diminta): simpan argumen sebagai attribute dengan nama yang sama, lalu panggil super().__init__() dengan pesan sesuai TODO.
  - Sesi.jual(jumlah): tolak jumlah <= 0 dengan JumlahTidakValid(jumlah); tolak jika terjual setelah ditambah melebihi kuota dengan TiketHabis; selain itu tambahkan.
  - Sesi.batal(jumlah): tolak jumlah <= 0 dengan JumlahTidakValid(jumlah); tolak jika jumlah lebih besar dari terjual dengan PembatalanMelebihi; selain itu kurangi.
  - Operasi yang ditolak tidak boleh mengubah terjual. Validasi dilakukan sebelum perubahan.
  - Seminar.cari(kode): gunakan EAFP. Akses dictionary di dalam try, lalu terjemahkan KeyError menjadi SesiTidakDitemukan(kode) dengan `from`.
  - Seminar.tukar(asal, tujuan, jumlah): cari asal lalu tujuan sebelum mengubah apa pun. Panggil batal() pada asal, lalu jual() pada tujuan. Jika langkah kedua gagal dengan SeminarError, kembalikan jumlah ke asal lalu teruskan exception yang sama dengan `raise`.
  - parse_jumlah(teks): ubah teks menjadi int. ValueError diterjemahkan menjadi JumlahTidakValid(teks) dengan `from`. Nilai nol atau negatif tidak diperiksa di sini, tetapi oleh jual()/batal().
  - Prosesor.jalankan(daftar_baris): gunakan try/except/else/finally untuk setiap baris sesuai TODO. Tangkap SeminarError saja. Exception lain, misalnya AttributeError karena bug, harus diteruskan; finally tetap menghitung baris tersebut.

  2. Format input

  Baris pertama n (0..10). n baris berikutnya: kode terjual kuota, dengan 0 <= terjual <= kuota dan kode unik tanpa spasi. Baris berikutnya m (0..20), lalu m baris perintah: `JUAL kode jumlah`, `BATAL kode jumlah`, atau `TUKAR asal tujuan jumlah`. Perintah dapat rusak: kata perintah tidak dikenal atau bukan huruf kapital, jumlah bagian salah, jumlah bukan bilangan bulat, atau kode tidak terdaftar. Baris perintah tidak pernah kosong.

  3. Format output

  Program utama mencetak satu log untuk setiap perintah, lalu baris berlabel Terjual, Diproses, Sebab JumlahTidakValid, Sebab SesiTidakDitemukan, Atribut PembatalanMelebihi, Atribut TiketHabis, dan Bug Diteruskan. Log berhasil berbentuk `nomor OK hasil`; log gagal berbentuk `nomor GAGAL NamaException: pesan`. Representasi object adalah `kode=terjual/kuota`.

  Method proses_baris() dan program utama sudah disediakan; jangan diubah. proses_baris() mengonversi jumlah terlebih dahulu sebelum mencari kode, sehingga `JUAL KODE_SALAH abc` gagal sebagai JumlahTidakValid.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `S1 100 500`
  - `S2 450 500`
  - `S3 0 300`
  - `8`
  - `JUAL S1 50`
  - `BATAL S3 1`
  - `TUKAR S1 S2 60`
  - `JUAL S2 abc`
  - `TUKAR S1 S3 20`
  - `BATAL S4 5`
  - `REFUND S1 1`
  - `JUAL S1 0`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `1 OK S1=150/500`
  - `2 GAGAL PembatalanMelebihi: terjual S3 0 kurang dari 1`
  - `3 GAGAL TiketHabis: sesi S2 melebihi kuota 500`
  - `4 GAGAL JumlahTidakValid: jumlah tidak valid: abc`
  - `5 OK S1=130/500 S3=20/300`
  - `6 GAGAL SesiTidakDitemukan: sesi S4 tidak ditemukan`
  - `7 GAGAL PerintahTidakValid: perintah tidak valid: 'REFUND S1 1'`
  - `8 GAGAL JumlahTidakValid: jumlah tidak valid: 0`
  - `Terjual: ['S1=130/500', 'S2=450/500', 'S3=20/300']`
  - `Diproses: 8 Gagal: 6`
  - `Sebab JumlahTidakValid: ValueError 12a`
  - `Sebab SesiTidakDitemukan: KeyError TIDAKADA`
  - `Atribut PembatalanMelebihi: UJI 100 150 100`
  - `Atribut TiketHabis: UJI 100 100`
  - `Bug Diteruskan: 2 1 1`
