prompt: |
  Tugas: Arsip Nilai Praktikum

  Asisten praktikum mengarsipkan komponen nilai dan menghasilkan laporan kelulusan tanpa kehilangan NIM dengan nol di depan.

  1. Spesifikasi

  - Model Mahasiswa memiliki data {"nama": "str", "nim": "str", "tugas": "int", "ujian": "int"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE CSV dan mengembalikan list object Mahasiswa dalam urutan masukan. Kolom numerik ['tugas', 'ujian'] dikonversi memakai int(); kode/NIM tetap string.
  - Aturan khusus: Nilai akhir = (40*tugas + 60*ujian) // 100. Status LULUS jika nilai akhir >= 60, selain itu ULANG. Simpan komponen asli, bukan nilai hasil perhitungan, pada JSON.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'mahasiswa' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Mahasiswa baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['nim', 'nama', 'nilai', 'status']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): jumlah mahasiswa LULUS (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (1..21), lalu n baris CSV TERMASUK header 'nim,nama,tugas,ujian'.

  Batas data: tugas dan ujian berupa integer 0..100; NIM unik berupa string digit. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `4`
  - `nim,nama,tugas,ujian`
  - `001,Ayu Pratama,80,90`
  - `002,Bima,40,50`
  - `003,Citra,60,60`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"mahasiswa": [{"nama": "Ayu Pratama", "nim": "001", "tugas": 80, "ujian": 90}, {"nama": "Bima", "nim": "002", "tugas": 40, "ujian": 50}, {"nama": "Citra", "nim": "003", "tugas": 60, "ujian": 60}]}`
  - `CSV: [['nim', 'nama', 'nilai', 'status'], ['001', 'Ayu Pratama', '86', 'LULUS'], ['002', 'Bima', '46', 'ULANG'], ['003', 'Citra', '60', 'LULUS']]`
  - `Log: ['mulai', 'simpan 3 object', 'simpan 3 object']`
  - `Ringkasan: 2`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
