  Tugas: Pembaruan Stok Koperasi

  Koperasi menerima daftar barang dari JSON dan perubahan stok dari file CSV terpisah.

  1. Spesifikasi

  - Model Barang memiliki data {"harga": "int", "kode": "str", "nama": "str", "stok": "int"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE JSON dan mengembalikan list object Barang dalam urutan masukan. Gunakan json.load(), ambil key 'barang', lalu bangun model lewat dari_dict().
  - Aturan khusus: terapkan_csv(path) membaca header kode,perubahan memakai csv.DictReader. Cari barang berkode sama lalu tambahkan int(perubahan) ke stok, sesuai urutan baris. Kode dapat muncul berulang; perubahan dapat negatif atau nol. Barang yang tidak disebut tetap utuh. Semua kode ada dan stok setelah SETIAP perubahan dijamin >= 0. Jangan menciptakan barang baru atau mengurutkan ulang data. Nilai persediaan per barang = stok*harga.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'barang' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Barang baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['kode', 'nama', 'stok', 'nilai']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): total nilai persediaan setelah perubahan (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (0..20), lalu n baris JSON; setiap baris adalah SATU object dengan struktur {"harga": "int", "kode": "str", "nama": "str", "stok": "int"} (label str/int/bool menunjukkan tipe, bukan nilai literal). Program utama membungkus object-object itu dalam dokumen {'barang': [...]} sebelum menulis file masukan.json. Setelah itu m (1..21), lalu m baris CSV perubahan TERMASUK header 'kode,perubahan'. CSV yang hanya berisi header berarti tidak ada perubahan.

  Batas data: stok dan harga berupa integer 0..1000000; kode unik. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan dan perubahan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `{"harga": 5000, "kode": "001", "nama": "Buku Tulis", "stok": 10}`
  - `{"harga": 2000, "kode": "002", "nama": "Pulpen", "stok": 5}`
  - `4`
  - `kode,perubahan`
  - `001,-3`
  - `002,2`
  - `001,1`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"barang": [{"harga": 5000, "kode": "001", "nama": "Buku Tulis", "stok": 8}, {"harga": 2000, "kode": "002", "nama": "Pulpen", "stok": 7}]}`
  - `CSV: [['kode', 'nama', 'stok', 'nilai'], ['001', 'Buku Tulis', '8', '40000'], ['002', 'Pulpen', '7', '14000']]`
  - `Log: ['mulai', 'simpan 2 object', 'simpan 2 object']`
  - `Ringkasan: 54000`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
