prompt: |
  Tugas: Arsip Peminjaman Bersarang

  Perpustakaan menyimpan satu peminjaman dengan object anggota dan beberapa judul buku di dalamnya.

  1. Spesifikasi

  - Model Pinjaman memiliki data {"anggota": {"nama": "str", "nim": "str"}, "buku": ["str"], "kode": "str"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE JSON dan mengembalikan list object Pinjaman dalam urutan masukan. Gunakan json.load(), ambil key 'pinjaman', lalu bangun model lewat dari_dict().
  - Aturan khusus: Anggota(nim, nama) sudah lengkap. Pinjaman(kode, anggota, buku) menyimpan Anggota dan list string judul. ke_dict() harus menghasilkan {'kode': str, 'anggota': {'nim': str, 'nama': str}, 'buku': list[str]} dengan dictionary dan list baru. dari_dict() membangun Pinjaman baru, Anggota baru, dan salinan list buku. Perubahan dictionary/list hasil serialisasi atau masukan deserialisasi tidak boleh mengubah object. ekspor_csv() menghasilkan satu baris per judul dalam urutan peminjaman lalu urutan buku. Pinjaman tanpa buku tetap disimpan ke JSON tetapi tidak menghasilkan baris data CSV.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'pinjaman' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Pinjaman baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['kode', 'nim', 'nama', 'judul']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): jumlah seluruh judul dalam semua peminjaman, termasuk judul berulang (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (0..20), lalu n baris JSON; setiap baris adalah SATU object dengan struktur {"anggota": {"nama": "str", "nim": "str"}, "buku": ["str"], "kode": "str"} (label str/int/bool menunjukkan tipe, bukan nilai literal). Program utama membungkus object-object itu dalam dokumen {'pinjaman': [...]} sebelum menulis file masukan.json.

  Batas data: kode unik; nim string digit; buku list 0..5 string, boleh mengandung judul berulang. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, Data Bersarang Independen, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `{"anggota": {"nama": "Ayu", "nim": "0001"}, "buku": ["Python", "OOP"], "kode": "001"}`
  - `{"anggota": {"nama": "Bima", "nim": "0002"}, "buku": ["Algoritma"], "kode": "002"}`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"pinjaman": [{"anggota": {"nama": "Ayu", "nim": "0001"}, "buku": ["Python", "OOP"], "kode": "001"}, {"anggota": {"nama": "Bima", "nim": "0002"}, "buku": ["Algoritma"], "kode": "002"}]}`
  - `CSV: [['kode', 'nim', 'nama', 'judul'], ['001', '0001', 'Ayu', 'Python'], ['001', '0001', 'Ayu', 'OOP'], ['002', '0002', 'Bima', 'Algoritma']]`
  - `Log: ['mulai', 'simpan 2 object', 'simpan 2 object']`
  - `Ringkasan: 3`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Data Bersarang Independen: True`
  - `Sumber Utuh: True`
