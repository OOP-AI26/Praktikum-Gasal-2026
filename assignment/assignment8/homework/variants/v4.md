prompt: |
  Tugas: Rekap Presensi dari CSV

  Asisten menerima catatan presensi beberapa sesi yang barisnya dapat berselang-seling antar mahasiswa.

  1. Spesifikasi

  - Model Presensi memiliki data {"nama": "str", "nim": "str", "sesi": "int", "status": "str"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE CSV dan mengembalikan list object Presensi dalam urutan masukan. Kolom numerik ['sesi'] dikonversi memakai int(); kode/NIM tetap string.
  - Aturan khusus: ekspor_csv() mengelompokkan berdasarkan nim. Pertahankan urutan kemunculan pertama NIM dan nama pertama yang ditemukan. Setiap status menambah satu hitungan hadir/izin/alpa. Persentase = 100*hadir // (hadir+izin+alpa); IZIN dan ALPA tetap masuk penyebut. JSON menyimpan SELURUH catatan asli berurutan, bukan hasil pengelompokan. Tidak perlu mengurutkan sesi.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'presensi' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Presensi baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['nim', 'nama', 'hadir', 'izin', 'alpa', 'persentase']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): jumlah catatan HADIR, bukan jumlah mahasiswa (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (1..21), lalu n baris CSV TERMASUK header 'nim,nama,sesi,status'.

  Batas data: sesi integer 1..100; status tepat HADIR/IZIN/ALPA; pasangan (nim,sesi) unik dan nama per nim konsisten. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `6`
  - `nim,nama,sesi,status`
  - `001,Ayu,1,HADIR`
  - `002,Bima,1,IZIN`
  - `001,Ayu,2,ALPA`
  - `002,Bima,2,HADIR`
  - `001,Ayu,3,HADIR`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"presensi": [{"nama": "Ayu", "nim": "001", "sesi": 1, "status": "HADIR"}, {"nama": "Bima", "nim": "002", "sesi": 1, "status": "IZIN"}, {"nama": "Ayu", "nim": "001", "sesi": 2, "status": "ALPA"}, {"nama": "Bima", "nim": "002", "sesi": 2, "status": "HADIR"}, {"nama": "Ayu", "nim": "001", "sesi": 3, "status": "HADIR"}]}`
  - `CSV: [['nim', 'nama', 'hadir', 'izin', 'alpa', 'persentase'], ['001', 'Ayu', '2', '0', '1', '66'], ['002', 'Bima', '1', '1', '0', '50']]`
  - `Log: ['mulai', 'simpan 5 object', 'simpan 5 object']`
  - `Ringkasan: 3`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
