  Arsipkan object pengeluaran ke JSON dan buat rekap CSV per kategori tanpa mengubah urutan transaksi.
prompt: |
  Tugas: Buku Kas Kegiatan Mahasiswa

  Bendahara ingin menyimpan detail pengeluaran sekaligus laporan kategori yang dapat dibuka di spreadsheet.

  1. Spesifikasi

  - Model Pengeluaran memiliki data {"kategori": "str", "kode": "str", "nominal": "int"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE CSV dan mengembalikan list object Pengeluaran dalam urutan masukan. Kolom numerik ['nominal'] dikonversi memakai int(); kode/NIM tetap string.
  - Aturan khusus: ekspor_csv() menulis satu baris per kategori, menurut urutan kemunculan pertama. jumlah_transaksi menghitung semua transaksi termasuk nominal nol; total menjumlah nominal kategori. Kategori dibandingkan persis (peka huruf besar/kecil). JSON tetap menyimpan seluruh transaksi asli sesuai urutan, bukan hanya rekap kategori.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'pengeluaran' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Pengeluaran baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['kategori', 'jumlah_transaksi', 'total']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): total nominal seluruh pengeluaran (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (1..21), lalu n baris CSV TERMASUK header 'kode,kategori,nominal'.

  Batas data: kode unik; nominal integer 0..1000000; kategori tidak kosong. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `4`
  - `kode,kategori,nominal`
  - `001,Konsumsi,10000`
  - `002,ATK,5000`
  - `003,Konsumsi,7000`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"pengeluaran": [{"kategori": "Konsumsi", "kode": "001", "nominal": 10000}, {"kategori": "ATK", "kode": "002", "nominal": 5000}, {"kategori": "Konsumsi", "kode": "003", "nominal": 7000}]}`
  - `CSV: [['kategori', 'jumlah_transaksi', 'total'], ['Konsumsi', '2', '17000'], ['ATK', '1', '5000']]`
  - `Log: ['mulai', 'simpan 3 object', 'simpan 3 object']`
  - `Ringkasan: 22000`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
