prompt: |
  Tugas: Daftar Tugas dan Status Persisten

  Tim praktikum menyimpan tugas dengan boolean JSON dan menerima pembaruan status melalui spreadsheet CSV.

  1. Spesifikasi

  - Model Tugas memiliki data {"judul": "str", "kode": "str", "prioritas": "int", "selesai": "bool"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE JSON dan mengembalikan list object Tugas dalam urutan masukan. Gunakan json.load(), ambil key 'tugas', lalu bangun model lewat dari_dict().
  - Aturan khusus: terapkan_csv(path) membaca header kode,selesai memakai csv.DictReader. Nilai selesai tepat 'ya' atau 'tidak'; petakan menjadi bool True/False. Jangan memakai bool(teks), karena bool('tidak') juga True. Perintah berulang untuk kode yang sama mengganti status sebelumnya; semua kode dijamin ada. JSON menyimpan semua tugas dan boolean native (true/false), bukan string. ekspor_csv() hanya menulis tugas dengan selesai False, urut prioritas MENAIK; untuk prioritas sama pertahankan urutan data semula. Jangan mengurutkan self.data secara in-place.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'tugas' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Tugas baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['kode', 'judul', 'prioritas']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): jumlah tugas yang belum selesai setelah perubahan (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (0..20), lalu n baris JSON; setiap baris adalah SATU object dengan struktur {"judul": "str", "kode": "str", "prioritas": "int", "selesai": "bool"} (label str/int/bool menunjukkan tipe, bukan nilai literal). Program utama membungkus object-object itu dalam dokumen {'tugas': [...]} sebelum menulis file masukan.json. Setelah itu m (1..21), lalu m baris CSV perubahan TERMASUK header 'kode,selesai'. CSV yang hanya berisi header berarti tidak ada perubahan.

  Batas data: kode unik; prioritas integer 1..5; selesai pada JSON berupa boolean, bukan string. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan dan perubahan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `{"judul": "Tulis Laporan", "kode": "001", "prioritas": 2, "selesai": false}`
  - `{"judul": "Baca Modul", "kode": "002", "prioritas": 1, "selesai": false}`
  - `{"judul": "Kumpulkan", "kode": "003", "prioritas": 3, "selesai": true}`
  - `3`
  - `kode,selesai`
  - `001,ya`
  - `003,tidak`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"tugas": [{"judul": "Tulis Laporan", "kode": "001", "prioritas": 2, "selesai": true}, {"judul": "Baca Modul", "kode": "002", "prioritas": 1, "selesai": false}, {"judul": "Kumpulkan", "kode": "003", "prioritas": 3, "selesai": false}]}`
  - `CSV: [['kode', 'judul', 'prioritas'], ['002', 'Baca Modul', '1'], ['003', 'Kumpulkan', '3']]`
  - `Log: ['mulai', 'simpan 3 object', 'simpan 3 object']`
  - `Ringkasan: 2`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
