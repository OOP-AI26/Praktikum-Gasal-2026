prompt: |
  Tugas: Arsip Penjualan dan Peringkat Omzet

  Stan bazar membutuhkan arsip transaksi dalam urutan kejadian dan laporan transaksi berdasarkan nilai penjualan.

  1. Spesifikasi

  - Model Penjualan memiliki data {"harga": "int", "jumlah": "int", "kode": "str", "nama": "str"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE CSV dan mengembalikan list object Penjualan dalam urutan masukan. Kolom numerik ['jumlah', 'harga'] dikonversi memakai int(); kode/NIM tetap string.
  - Aturan khusus: Subtotal transaksi = jumlah*harga. ekspor_csv() menulis seluruh transaksi menurut subtotal MENURUN. Jika subtotal sama, pertahankan urutan semula (stable sort). Jangan mengurutkan self.data secara in-place. Kode mengidentifikasi transaksi dan unik; nama produk boleh berulang. JSON menyimpan komponen jumlah dan harga dalam urutan masukan, tanpa key subtotal tambahan.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'penjualan' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Penjualan baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['kode', 'nama', 'jumlah', 'harga', 'subtotal']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): total omzet seluruh transaksi (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (1..21), lalu n baris CSV TERMASUK header 'kode,nama,jumlah,harga'.

  Batas data: kode unik; jumlah dan harga integer 0..1000000. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `4`
  - `kode,nama,jumlah,harga`
  - `001,Buku,2,10000`
  - `002,Pulpen,5,5000`
  - `003,Stiker,4,1000`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"penjualan": [{"harga": 10000, "jumlah": 2, "kode": "001", "nama": "Buku"}, {"harga": 5000, "jumlah": 5, "kode": "002", "nama": "Pulpen"}, {"harga": 1000, "jumlah": 4, "kode": "003", "nama": "Stiker"}]}`
  - `CSV: [['kode', 'nama', 'jumlah', 'harga', 'subtotal'], ['002', 'Pulpen', '5', '5000', '25000'], ['001', 'Buku', '2', '10000', '20000'], ['003', 'Stiker', '4', '1000', '4000']]`
  - `Log: ['mulai', 'simpan 3 object', 'simpan 3 object']`
  - `Ringkasan: 49000`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
