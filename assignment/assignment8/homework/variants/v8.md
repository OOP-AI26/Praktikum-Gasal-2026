  Tugas: Arsip Riwayat Sensor

  Laboratorium menyimpan riwayat pembacaan sensor sebagai list integer dan membuat ringkasan tanpa menghapus data aslinya.

  1. Spesifikasi

  - Model Sensor memiliki data {"bacaan": ["int"], "kode": "str", "lokasi": "str"}. Lengkapi ke_dict() dan dari_dict(): gunakan tepat key tersebut, buat representasi dan instance baru, pertahankan tipe, serta jangan mengubah masukan. Jangan menambahkan field turunan pada JSON.
  - baca_data(path) membaca FILE JSON dan mengembalikan list object Sensor dalam urutan masukan. Gunakan json.load(), ambil key 'sensor', lalu bangun model lewat dari_dict().
  - Aturan khusus: Sensor(kode, lokasi, bacaan) menyimpan list integer. ke_dict() menghasilkan dictionary baru dengan salinan list bacaan, dan dari_dict() membuat Sensor serta list baru tanpa berbagi list dengan dictionary masukan. CSV berisi satu baris untuk SETIAP sensor menurut urutan semula: banyak=len(bacaan), minimum=min(bacaan), maksimum=max(bacaan), total=sum(bacaan). Jika bacaan kosong, banyak dan total 0, minimum dan maksimum field kosong (''). Nilai negatif sah; jangan mengganti bacaan nol dengan field kosong. JSON tetap menyimpan list lengkap sesuai urutan, tanpa key ringkasan tambahan.
  - Arsip.simpan_json(path): tulis satu dictionary dengan key 'sensor' berisi list hasil ke_dict() dalam urutan self.data. Gunakan json.dump(..., ensure_ascii=False, indent=2) dan mode 'w'. Arsip.muat_json(path): baca dengan json.load() dan kembalikan Arsip berisi instance Sensor baru melalui dari_dict().
  - ekspor_csv(path): mode 'w', csv.writer, header tepat ['kode', 'lokasi', 'banyak', 'minimum', 'maksimum', 'total']. Tetap tulis header ketika tidak ada baris hasil. Ekspor dan ringkasan tidak boleh mengubah object atau urutan self.data.
  - ringkasan(): jumlah seluruh bacaan dari semua sensor, termasuk nilai nol (int); data kosong menghasilkan 0. catat_log(path): mode 'a', tambah tepat `simpan N object` diikuti newline, N = jumlah object sumber (BUKAN jumlah baris laporan).
  - Semua akses file wajib memakai `with open(...)`, encoding='utf-8', dan newline='' khusus CSV. Model/service tidak mencetak. Gunakan standard library; tanpa pandas, database, pickle, eval(), atau GUI. Tidak perlu membuat custom context manager atau package.

  2. Format input

  Baris pertama n (0..20), lalu n baris JSON; setiap baris adalah SATU object dengan struktur {"bacaan": ["int"], "kode": "str", "lokasi": "str"} (label str/int/bool menunjukkan tipe, bukan nilai literal). Program utama membungkus object-object itu dalam dokumen {'sensor': [...]} sebelum menulis file masukan.json.

  Batas data: kode unik; bacaan list 0..10 integer -1000..1000. Semua string tidak mengandung newline. String boleh mengandung spasi, Unicode, koma, atau tanda kutip; gunakan quoting CSV/JSON yang sah. Data selalu valid sesuai kontrak. Nama, judul, lokasi, serta kategori dipertahankan persis; jangan strip() isi field. Tidak ada file hilang atau dokumen rusak dalam test resmi; fokus tugas ini adalah file handling dan serialisasi, bukan hierarki exception baru.

  Program utama menyiapkan file asli dalam TemporaryDirectory agar kode yang sama berjalan di komputer dan filesystem Python browser. Lengkapi TODO, jangan ubah program utama, signature, atau test. Jangan mengganti operasi FILE dengan pemrosesan stdin. Folder sementara dibersihkan setelah program selesai; Save File menyimpan source Python, bukan file data hasil run.

  3. Format output

  Program utama mencetak dokumen JSON (key diurutkan hanya untuk tampilan), seluruh CSV sebagai list baris string, Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, Data Bersarang Independen, dan Sumber Utuh. Data Utuh memeriksa nilai dan urutan object sebelum/sesudah ekspor serta ringkasan. JSON/CSV ditulis dua kali ke file tujuan yang sebelumnya berisi data lama untuk memeriksa mode 'w'; log ditambah dua kali ke file berisi `mulai` untuk memeriksa mode 'a'. File masukan harus tetap utuh.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `2`
  - `{"bacaan": [20, 22, 18], "kode": "001", "lokasi": "Ruang A"}`
  - `{"bacaan": [0, -2, 5], "kode": "002", "lokasi": "Ruang B"}`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"sensor": [{"bacaan": [20, 22, 18], "kode": "001", "lokasi": "Ruang A"}, {"bacaan": [0, -2, 5], "kode": "002", "lokasi": "Ruang B"}]}`
  - `CSV: [['kode', 'lokasi', 'banyak', 'minimum', 'maksimum', 'total'], ['001', 'Ruang A', '3', '18', '22', '60'], ['002', 'Ruang B', '3', '-2', '5', '3']]`
  - `Log: ['mulai', 'simpan 2 object', 'simpan 2 object']`
  - `Ringkasan: 6`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Data Bersarang Independen: True`
  - `Sumber Utuh: True`
