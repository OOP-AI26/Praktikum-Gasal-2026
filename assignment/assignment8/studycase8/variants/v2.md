prompt: |
  Tugas: Koleksi Buku Pojok Baca

  Pojok baca menyimpan jumlah eksemplar setiap judul buku dalam arsip portabel. Lengkapi alur CSV -> object Buku -> file JSON -> object baru -> CSV, serta log teks yang ditambahkan tanpa menghapus isi sebelumnya.

  1. Spesifikasi

  - Buku(kode, nama, eksemplar) sudah disediakan. ke_dict() menghasilkan dictionary baru berisi tepat kode (str), nama (str), dan eksemplar (int). dari_dict() mengembalikan instance baru tanpa mengubah dictionary masukan.
  - baca_data(path) membaca CSV menggunakan csv.DictReader dan mengembalikan list Buku. Pertahankan kode sebagai string (termasuk nol di depan), nama apa adanya, dan urutan baris; konversi eksemplar menjadi int.
  - Arsip.simpan_json(path) menulis satu dictionary dengan key 'buku' berisi list hasil ke_dict(). Gunakan json.dump(..., ensure_ascii=False, indent=2), mode 'w'. Memanggilnya berulang harus mengganti seluruh arsip lama.
  - Arsip.muat_json(path) adalah classmethod: baca memakai json.load(), bangun kembali setiap Buku melalui dari_dict(), lalu kembalikan Arsip baru. Jangan mengembalikan dictionary mentah sebagai model.
  - ekspor_csv(path) menulis header ['kode', 'nama', 'eksemplar'] dan seluruh data dalam urutan semula memakai csv.writer dan mode 'w'. Data kosong tetap memiliki header.
  - catat_log(path) memakai mode 'a' dan menulis tepat `simpan N object` diikuti newline, dengan N jumlah object. Isi log sebelumnya tetap ada.
  - ringkasan() mengembalikan total eksemplar sebagai int, atau 0 ketika data kosong. Model dan Arsip tidak mencetak.
  - Semua akses file wajib memakai context manager `with open(...)` dan encoding='utf-8'. Tambahkan newline='' pada pembacaan dan penulisan CSV. Jangan membuat context manager sendiri, menggunakan split(',') untuk CSV, atau menyimpan object langsung ke json.dump().

  2. Format input

  Baris pertama n (1..21), lalu n baris isi CSV, TERMASUK header `kode,nama,eksemplar`. Kode unik dan tidak kosong. eksemplar berupa integer 0..1000000. Nama boleh berisi spasi, Unicode, koma, atau tanda kutip sesuai quoting CSV, tetapi tidak mengandung newline. Semua file dan data valid; tidak perlu menambahkan validasi di luar kontrak ini.

  Program utama membuat file input dan file tujuan lama dalam folder sementara, lalu memanggil method yang kamu lengkapi. Satu file Python tetap cukup. Jangan mengganti pembacaan file dengan pemrosesan input() di TODO.

  3. Format output

  Program utama mencetak JSON (key diurutkan hanya untuk tampilan), CSV sebagai list baris string, isi Log, Ringkasan, Data Utuh, Object Baru, Tipe Benar, dan Sumber Utuh. Dua kali penulisan JSON/CSV tidak boleh menggandakan data; dua kali penambahan log harus mempertahankan baris `mulai`. Data Utuh memeriksa bahwa ekspor dan ringkasan tidak mengubah nilai atau urutan object. Program utama juga memeriksa bahwa file sumber tidak berubah dan object yang dimuat merupakan instance baru.

  4. Contoh Input

  Setiap butir berikut adalah satu baris input.
  - `3`
  - `kode,nama,eksemplar`
  - `001,Dasar Python,10`
  - `002,OOP Lanjutan,5`

  5. Contoh Output

  Setiap butir berikut adalah satu baris output.
  - `JSON: {"buku": [{"eksemplar": 10, "kode": "001", "nama": "Dasar Python"}, {"eksemplar": 5, "kode": "002", "nama": "OOP Lanjutan"}]}`
  - `CSV: [['kode', 'nama', 'eksemplar'], ['001', 'Dasar Python', '10'], ['002', 'OOP Lanjutan', '5']]`
  - `Log: ['mulai', 'simpan 2 object', 'simpan 2 object']`
  - `Ringkasan: 15`
  - `Data Utuh: True`
  - `Object Baru: True`
  - `Tipe Benar: True`
  - `Sumber Utuh: True`
